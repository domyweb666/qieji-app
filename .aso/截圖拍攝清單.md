# 10 張展示圖：照著拍

> 用 TestFlight 的茄記 1.1 拍。你已經買了完整版，所以 10 張都拍得到。
> 拍完把 10 個檔丟進 `E:\茄記\qieji-1.1\store-assets\1.1.0\raw\`，跟我說一聲，我來合成。

## 拍之前（做一次就好）

1. iPhone「設定 › 螢幕顯示與亮度」選**淺色**。茄記「設定 › 外觀」選**跟隨系統**。
2. 茄記「設定 › 紙上的字級」選**標準**。
3. 控制中心打開**勿擾**，免得通知橫幅跳進畫面。
4. 電量充到 80% 以上，站在訊號滿格的地方。
5. 截圖的按法：**側邊鍵＋音量上鍵**同時按一下。不要用螢幕錄影。
6. 截完左下角會冒一個小縮圖，**不要點它**，等它自己滑走。點進去編輯過的圖尺寸會不對。

## 先備好要入鏡的紙

你自己真的在用的紙不要入鏡。先開這些示範用的，拍完再刪。

**A. 主角這張**：左上清單名 ›「新的一張」，再按右上 ⋯ ›「改名字」打「想到的事」，⋯ 裡的顏色選**玉米**（黃色那顆）。按 ＋ 照下面順序一行一行記（先記的會在下面，所以從最後一行開始記）：

1. 轉接頭到底放哪了
2. 下次經過記得買洗衣精
3. 陽台的薄荷該換大一點的盆
4. 那本書的書名再查一下
5. 問牙醫下個月還有沒有空
6. 巷口那間麵店星期一沒開

記完由上到下應該是 6、5、4、3、2、1。然後把「下次經過記得買洗衣精」**往右滑劃掉**。

**B. 另外六張**（只要名字和顏色，裡面隨便記一行就好）：

| 名字 | 顏色 |
|---|---|
| 要買的 | 茄子 |
| 書單 | 紅蘿蔔 |
| 旅行 | 藍莓 |
| 點子 | 青蔥 |
| 電影 | 香菇 |
| 店家 | 黑豆 |

**C. 三張要丟進最近刪除的**：再開三張，名字打「舊的購物清單」「上個月的事」「搬家要帶的」，各記一行。

## 一張一張拍

### 1-paper.png　主畫面

1. 打開「想到的事」。
2. 確認：六行、一行劃掉、鍵盤沒開、右下角看得到 ＋。
3. 截圖。

### 2-compose.png　正在打字

1. 還在「想到的事」，按右下角 **＋**。
2. 打「週末去看畫展」，**不要按勾**，字留在輸入框裡。
3. 選字列如果還有注音符號沒選完，先選完，輸入框裡只剩中文。
4. 截圖。
5. 截完先把輸入框裡的字**全部刪掉**，再點紙上空白處收起鍵盤。字沒刪就點空白處，它會被記成一行；真的記下去了就往左滑刪掉。

### 3-strike.png　劃掉兩行

1. 還在「想到的事」，把「轉接頭到底放哪了」也**往右滑劃掉**。現在有兩行劃掉。
2. 截圖。
3. 截完把「轉接頭到底放哪了」再往右滑一次恢復（第 8 張的小工具要用一行劃掉的樣子）。

### 4-start.png　從這裡開始

1. 左上清單名 › 找到「從這裡開始」點進去。
2. 如果你早就把它刪了：到目錄最下面「最近刪除」看有沒有；都沒有的話跳過這張，跟我說，我改用別的畫面。
3. 捲到最上面，七行都看得到。
4. 截圖。

### 5-colors.png　顏色選單

1. 打開「店家」那張。
2. 按右上 **⋯**，選單打開，最上面看得到一排顏色圓點。
3. 截圖。
4. 點選單外面關掉。

### 6-directory.png　目錄

1. 左上清單名 › 最下面「管理所有清單」。
2. 確認看得到七塊不同顏色的方磚（想到的事＋B 的六張），還有搜尋框。你自己的紙如果也在這頁，先把它們拖到一個資料夾裡，或暫時改個不透露內容的名字。
3. 不要進入編輯模式（方磚不要抖）。
4. 截圖。

### 7-trash.png　最近刪除

1. 先把 C 的三張刪掉：一張一張打開，⋯ ›「刪除這張」。
2. 回目錄，捲到最下面點「最近刪除」。
3. 確認裡面看得到那三張。有你自己的東西在裡面的話，先把它還原出去。
4. 截圖。

### 8-widget.png　主畫面小工具

1. 回 iPhone 主畫面，往右滑到最後，再多拉出一頁**空白頁**（按住空白處進入編輯，把一個 app 往右拖出去就會多一頁，再把那個 app 拖回去）。
2. 在空白頁按住空白處 › 左上「編輯」›「加入小工具」› 搜「茄記」› 選最小的正方形那個（1.0 的圖用的就是它）›「加入小工具」。
3. 這一頁只留這個小工具，沒有其他 app 圖示。
4. 小工具上應該是「想到的事」和前幾行。不是的話先打開茄記點進「想到的事」再回來。
5. 截圖。

### 9-control.png　控制中心

1. 從右上角往下滑，打開控制中心。
2. 如果還沒有「記一行」：按左上角 **＋** ›「新增控制項目」› 搜「茄記」› 點「記一行」。
3. 把「記一行」拖到畫面中間偏上、好認的位置，點空白處結束編輯。
4. 確認控制中心上沒有正在播放的歌名、沒有你不想公開的東西。
5. 截圖。

### 10-icloud.png　設定頁

1. 打開茄記，任一張紙右上 **⋯** ›「設定」。
2. 確認「iCloud 同步」的開關是開的，下面那行小字寫「已同步」或「同步開著」。
3. 畫面停在最上面，看得到「一般」「資料」「購買」這幾塊。
4. 截圖。

## 傳到電腦

1. iPhone 用傳輸線接電腦，或開 icloud.com 的照片下載。**不要用 LINE 傳**，會被壓縮。
2. 10 張照拍的順序改檔名：`1-paper.png`、`2-compose.png`、`3-strike.png`、`4-start.png`、`5-colors.png`、`6-directory.png`、`7-trash.png`、`8-widget.png`、`9-control.png`、`10-icloud.png`。副檔名是 .jpg 或 .heic 也沒關係，照原本的留著，前面的名字對就好。
3. 放進 `E:\茄記\qieji-1.1\store-assets\1.1.0\raw\`。
4. 每張應該是 1206 × 2622。不是也先丟進來，我看了再處理。

## 拍完收尾

把 A、B、C 那些示範用的紙刪掉，最近刪除裡的也清掉。小工具和控制中心的「記一行」看你要不要留。
