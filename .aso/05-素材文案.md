### 閘門 4 怎麼測

1. 找一個沒看過茄記的人。
2. 手機上打開 `store-assets/1.1.0-草稿/預覽總覽.png`，只讓他看前三張，5 秒後收起來。
3. 問：「這是什麼 app？」「你覺得它跟你現在用的有什麼不一樣？」
4. 把他講的原話記下來，一個字都不要幫他修。
5. 他如果講得出「記事情的」加上「不會催」或「不用管期限」，過。只講得出「記事本」，第三張要改。

紀錄格式：日期｜誰（跟茄記的關係）｜原話｜過／退。寫進 `閘門紀錄.md`。

## 二、描述

只有第一句一定會被看到。現在的第一句已經在講「是什麼」，補上最大的疑慮（要不要註冊）。其他段落是你原本的字，一個字沒動。

**第一段換成：**

```
茄記用來隨手記零碎的想法，不用註冊，打開就能打字。記下來就不用再記在腦裡，大部分可能就放著，少部分有做到就劃掉。
```

第二段以後照 `.vibe/送審貼上版-1.1.0.md` 現在那份，不改。那份沒有塞關鍵字、沒有價格，承諾也都對得上。

（如果加了英國英文語系，英文描述另外寫，第一句加「The app interface is in Traditional Chinese.」。等你決定要不要加那組再寫。）

## 三、宣傳文字（78／170 字）

宣傳文字不用審、隨時能改、不影響排名，放會變的事。1.1 上架那幾週放收費方式的改變，一個月後換回原本那段。

**1.1 上架時：**

```
1.1 新增茄記完整版，一次付清，不是訂閱。記、劃掉、整理、搜尋照樣免費，沒有廣告。打開就是上次那張紙，右下角 ＋ 直接打字。沒有到期日，也不會跳通知催你。
```

**一個月後換回：**

```
想到就記，不用再記在腦裡。打開就是上次那張紙，右下角 ＋ 直接打字。沒有到期日，也不會跳通知催你。不用帳號，沒有廣告。
```

現在不做。等你決定要在 Threads、IG、YouTube 發茄記的時候，每個入口開一頁（只能換截圖、預覽影片、宣傳文字，名稱副標不能換）。外面進來的人沒看過搜尋卡片，那一頁的第一張用第 1 張就可以，它自己講得清楚這是什麼。
