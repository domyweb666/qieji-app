## 二、「你要付出的」那張表（4 列要改）

| 列 | 現在 | 改成 |

| 費用 | 免費下載，第一版沒有付費項目 | 免費下載，沒有廣告。記、劃掉、整理、搜尋都免費。茄記完整版另外買，一次付清，不是訂閱 |
| 權限 | 不跟你要任何系統權限 | 不跟你要相簿、相機、麥克風、定位。把清單上鎖之後，打開它要過 Face ID |

價格要不要寫在網頁上你決定。App Store 的素材不能放價格，自己的網站可以。

## 三、要新增的一段：「茄記完整版」

放在「怎麼用」和「裝起來」中間。內容照 App Store 描述那段：

```
茄記完整版

一次付清，不是訂閱。買了多這些：

・iCloud 同步：換手機或刪掉重裝，紙會自己回來
・控制中心加一顆「記一行」，鎖著螢幕想到事情，按一下解鎖就能打字（iOS 18 以上）。這顆也能放到鎖定畫面下方，或指定給動作按鈕
・主畫面和鎖定畫面的小工具，看一眼上次那張紙記了什麼
・封面圖：紙的頂部放一張自己的照片，目錄裡那塊磚也換成它
・個別上鎖：挑幾張鎖起來，打開要 Face ID
・記事本：不分行，一整頁照你的意思寫
・紙上的字級：小、標準、大、特大

控制中心和小工具是我自己最常用的。之後新增的完整版功能也包含在內，不用再付。同一個家庭群組的人不用再買。
```

## 四、常見問題要加、要改的

- 「換手機或刪掉重裝，紙會回來嗎？」的答案換成支援頁 1.1 那一版。
- 新增三題，答案從 `.vibe/支援頁-1.1.0.md` 抄：「茄記完整版是什麼？要一直付錢嗎？」「我買過了，為什麼還是鎖著？」「我以前有 iCloud 同步，更新後怎麼停了？」

## 五、不用動的

大標「想到就記，不會催你。」、第一段介紹、「它不會做的事」、五個手勢、九種顏色、最近刪除 30 天、一張紙 1000 行、只有 iPhone。

App Store 上的名稱改成「茄記：想到就記的隨手備忘錄」之後，網頁標題「茄記：想到就記，不會催你的 iPhone 隨手記」可以不改，兩邊開頭都是「茄記：想到就記」。
