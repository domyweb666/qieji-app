茄記 2.0 目錄面板：第一批做到哪

2026-11-21。樣子照 1.1 搬，尺寸、色碼都是 1.1 的數字。要你選的只有一件事：第一批先做到哪一段。

一、搬過來長這樣（跟 1.1 同一套尺寸）

入口照 1.1：點左上清單名 → 切換清單 →「管理所有清單」→ 目錄從下面升上來，上面留一截紙。長按一行的「搬到…」也是開這個面板。

二、第一批做到哪

甲　先能看、能點

  • 面板跟著手指升起、往下拉收起
  • 方磚、資料夾磚、頁點、左右翻頁
  • 點磚換紙（磚放大鋪滿那個動畫）
  • 點資料夾打開、裡面翻頁
  • 搜尋（列出符合的行）、新的一張
  • 最近刪除、設定兩列
  • 「搬到…」選一張
  • 沒有：長按選單、抖動、拖曳
圖 1、2。改顏色、釘選、刪除要回紙上的 ⋯ 做。磚的順序動不了。

乙　甲＋長按選單我推薦

  • 甲的全部
  • 長按磚：換顏色、釘選、刪除（留空位、可復原）
  • 資料夾名字點了能改
  • VoiceOver 的動作（改名字、放進資料夾、往前往後移）
  • 沒有：抖動、拖曳排磚、疊成資料夾
圖 1、2、4。不靠拖的都到齊；資料夾只能用 1.1 做好的那些，新的疊不出來。模擬器驗得完，不用等真機。

丙　一次全做

  • 乙的全部
  • 長按後拖、抖動中直接拖
  • 換位、空位、跨頁、新開一頁
  • 疊成資料夾、拖進拖出、資料夾裡排順序
  • 抖動中的「−」、空白處翻頁
圖 1–4。拖曳這段在 1.1 佔目錄程式的六成，11/02–11/04 靠你真機回報來回改了三天。現在還沒有上真機的路，我做完也只能在模擬器驗，手感等於沒驗。

三、我推薦乙的原因

甲乙丙
目錄裡能做的事看、找、換紙加上改色、釘選、刪除、改資料夾名跟 1.1 一樣
模擬器驗得完嗎可以可以拖曳只驗得到「有作用」，順不順要真機
卡在等真機的部分升起收起的手感同甲再加整段拖曳
之後接拖曳磚先用「位置」排好，之後加拖曳不用重排版（1.1 踩過：磚一換容器手勢就斷）—

拖曳是 1.1 最花真機來回的一段，放到真機的路定了之後做，改一輪你就能摸一輪。乙做完，目錄在 2.0 就不是缺的那塊了。

四、選乙的話，這幾件我會直接照 1.1 做

  • 切換清單改回 1.1 的內容：新的一張、釘選的、最近開過的、「管理所有清單」。現在 Swift 版是把所有清單列成一長串，目錄做好就不需要了
  • 上鎖的紙：磚照畫（色塊、字、左上一個鎖），點了還是只看得到名字（Face ID 還沒搬）
  • 封面圖還沒搬：有封面的紙先畫成色塊加字
  • 面板用自己做的，不用系統的半高面板（1.1 的目錄本來就是自己做的；11/04 切換清單試過系統那種，你在真機看了四角都圓、關不掉，當時換掉）
