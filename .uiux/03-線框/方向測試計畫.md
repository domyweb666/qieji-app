# 方向測試計畫（閘門 2，暫定 v0）

> Agent 不當測試者，也不選方向。這份只寫怎麼測、怎麼記；方向由多米看完紀錄自己選。

## 測什麼

三個方向一起給同一個人測，看的是**第一下點哪裡**、有沒有找不到。

| 題號 | 題目（照唸，不改字） | 用哪個狀態 |
|---|---|---|
| W1 | 你剛想到一個點子，想在忘記之前把它記進這張清單。 | 正常 |
| W2 | 這是一張剛開好的新清單，你想寫下第一個點子。 | 空清單 |
| W3 | 你已經往下看了很多，現在又想到一個新點子，要記下來。 | 最壞內容（捲到中間） |
| W4 | 你剛打完一個點子，馬上又想到另一個，接著記。 | 鍵盤升起 |
| W5 | 其中一個點子你已經做到了，想把它劃掉。 | 正常 |

W5 在線框上測不到滑動，只看他第一下想點哪裡、會不會往右滑，記下來就好。

## 找誰

- 3～5 個**沒看過茄記**的人。多米自己、看過你做這個 app 的人不算。
- 平常有在手機上記東西的人優先。
- 熟人會比較客氣；找不到陌生人的話照測，但在紀錄上標「降級：熟人」。

## 怎麼測

1. 在 iPhone 17 上打開線框頁，**關掉「顯示點擊範圍」**，點要測的那張「全螢幕（實際尺寸）」。
2. 開場只說：「這是一個還沒做好的記事 app，畫面是灰色的很正常。我唸一個情境，你用一隻手拿手機，點你會點的地方。」不教怎麼用。
3. 唸題目，請他單手點。全螢幕模式會在點的位置留下編號圓點，截圖存起來。
4. 他問「這是什麼」就回「你覺得呢？」，不解釋。
5. 三個方向的順序每個人輪換，避免後面的方向占便宜：

| 受測者 | 順序 |
|---|---|
| 1、4 | A → B → C |
| 2、5 | B → C → A |
| 3 | C → A → B |

6. 每個人做完問一句：「哪一個你會最快記下東西？為什麼？」原話記下來。

## 這份測不到的

- 手感、鍵盤真的升起來的樣子、滑動手勢：線框是圖，不是 app。
- 選好方向之後，要做成能操作的「灰盒子」裝到 iPhone 17 上再測一輪（閘門 2 第二段）。
