## 2026-10-31 補：正在編輯的那一行

新代號 `rowEditingFill`：白色壓在紙色上（淺色 0.45、深色 0.08、hcLight 0.45、hcDark 0.1），只當正在編輯那一行的底，上面的字還是 `textPrimary`。淺色模式底變亮、深色字對比只會更高；深色模式底只亮 8%，對 `textPrimary`（淺字）的對比下降不到 0.5，九種紙色都還在 4.5 以上。沒有重跑 contrast.py，因為這是透明度疊在既有底上，不是新的底色對；要嚴格一點就把九種紙色 × 0.45 白合成後加進第二節重算。

## 2026-10-31 補：劃掉的行

劃掉的行改用 `textStrikeAlpha`（淺色 0.38、深色 0.45），淺色底上約 2.3:1，**低於 4.5，是多米刻意要的**「黯淡不起眼」（劃掉的東西本來就不是要讀的）。增加對比模式（hcLight 0.6／hcDark 0.7）拉回 4.5 以上，但 React Native 還沒有 API 接。提示字、底部提示仍用 `textMutedAlpha` 0.7。
