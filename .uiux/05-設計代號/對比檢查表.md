# 對比檢查表

> 計算方式：WCAG 2.x 相對亮度公式，用 skill 的 `scripts/contrast.py` 算，不目測。半透明字色先跟底色合成成不透明色再算。
> 門檻：一般文字 4.5:1、大字與非文字元件 3:1（15pt 粗算不算大字不確定，照規則當一般文字）。
> 日期：2026-10-31。淺色＝多米定案值；深色、增加對比＝候選值（寫在 `Tokens-暫定.ts`），算過但沒在真機看過。
> 狀態：**四種模式 59 組全部通過**（contrast.py exit 0）。
> 重跑方式：`python -I -X utf8 gen_pairs.py pairs.json`，再 `python -I -X utf8 <skill>/scripts/contrast.py pairs.json`。`gen_pairs.py` 在本資料夾，色值改了要跟 `Tokens-暫定.ts` 一起改。
> WCAG 下一版的新對比算法定案後，判準要改（2-6、3-5 失效邊界 4）。
