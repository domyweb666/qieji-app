# 茄記｜打掉重來的設計提案（分支 `redesign/claude-blank-slate`）

> 多米 2026-10-31 問：「如果 UI、UX 全部打掉，你重新設計的話呢？」
> 這份是 Claude 的答案。它刻意跳過 `.uiux/` 的五道閘門，也推翻幾條 HANDOFF 標「別再動」的決定，所以只活在這條分支上，master 不動。
> 可以點的原型在同資料夾 `原型.html`（淺色、深色跟系統走）。

## 一、我只改一件事，其他都是這件事長出來的

現在的茄記：**首頁是目錄，記之前要先走進一張清單。**

```
打開 → 首頁（清單列表）→ 點一張 → 點「＋ 新增一行」→ 打字
```

從首頁出發要四步，開新清單還要先打標題、按下一步、鍵盤收起、再點「新增一行」。
核心動作卡說核心動詞是「記」，但畫面上真正的主角一直是「清單」。

重新設計把這句話反過來：**紙是家，打開就能寫。**

```
打開 → 紙（上次那張）→ 拇指底下就是輸入列 → 打字
```

- app 的根畫面不再是目錄，而是**一張紙**（就是現在的清單頁，但重畫）。
- 畫面**最底下常駐一條輸入列**「記點什麼…」。打字、按換行，那行就出現在紙的最上面。不用先點「新增一行」。
- 要換別張、開新的一張、找舊東西：**點最上面的清單名**（旁邊有個 ⌄），目錄從下面升起來，點一張就換紙。
- 目錄從「根畫面」降級成「一張面板」。搜尋、篩選、最近刪除、備份都搬到面板裡。

這跟 02-流程的 ❓A 乙、丙兩案不一樣：不需要特殊的「隨手記」清單，也不會冒出一堆沒標題的清單。每一行還是屬於某張紙，只是「選哪張」這一步從「每次記之前」變成「想換的時候才做」。

## 二、四個畫面變成兩個半

| 現在 | 重設計 | 說明 |
|---|---|---|
| 首頁（清單列表） | **目錄面板**（半頁） | 不再是根。色紙磚兩欄排，只有顏色與名字，沒有時間、沒有預覽、沒有數字。釘選的在前。第一塊永遠是虛線的「＋ 新的一張」 |
| 清單頁 | **紙**（根畫面） | 整頁底色就是紙的顏色。行是純文字，不再一行一張卡片，只留一條很淡的橫線（像筆記本的格線）。沒有勾圈 |
| 顏色面板 | 併進紙的 ⋯ 選單 | 九個色塊一排，點了紙直接換色，不另開一頁 |
| 最近刪除 | 目錄面板最底下一列 | 有東西才出現，淡灰。點進去還是獨立一頁（還原／永久刪除不變） |
| 「＋ 新增一行」 | **拿掉** | 被底部輸入列取代 |
| 右下角 ＋（開新清單） | **拿掉** | 「＋ 新的一張」在目錄面板第一格 |

## 三、記、劃掉、刪、搬：每個動作怎麼做

| 動作 | 怎麼做 | 跟現在差在哪 |
|---|---|---|
| 記 | 底部輸入列打字 → 換行 | 現在要先點「新增一行」，鍵盤才升起 |
| 改一行 | 點那一行，原地變成可以打字 | 一樣 |
| 劃掉 | 往右滑（保留）；**長按那一行也有「劃掉」** | 隱藏手勢多一條看得見的路，VoiceOver 也走得通（03-線框 ❓ 的方案 1） |
| 劃掉的行去哪 | 沉到紙的最底下，一條細線隔開，寫「劃掉的 ⌄」收起來；**不印數字** | 現在留在原位變淡；劃掉多了會卡在中間 |
| 刪一行 | 往左滑（保留）；長按也有 | **刪掉的行進「最近刪除」裡那張紙的影子**，不再只有 3.5 秒 |
| 搬到別張 | 長按 →「搬到…」→ 目錄面板 | 新增。因為「先寫再放」會需要事後整理 |
| 開新的一張 | 目錄面板第一格 →「新的一張」→ 直接落在輸入列打第一行 | **標題變成選填**。沒打名字的紙，在目錄上就用第一行當名字 |
| 命名 | ⋯ →「改名字」；點名字是換一張，不是改名 | 現在是新清單一開就逼你先打標題 |
| 換顏色、釘選、分享、複製全文、清掉劃掉的、刪除這張 | 紙右上 ⋯ | 一樣，只是顏色併進來 |

## 四、長相

- **底色**：整張紙就是那個顏色（沿用九種清單色 `bg`），介面色沿用 tokens 的奶油白／茄紫，深色模式用同一份深色值。不新增顏色。
- **字**：系統字體。紙的名字 28pt 粗體；行 17pt、行高 27（沿用 `bodyLine`）。
- **行**：沒有卡片、沒有圓角框。行與行之間一條 1pt 的 `rule` 色橫線，左右留 20。劃掉用刪除線＋ `textMuted`。
- **輸入列**：奶油白藥丸、`shadowSoft`、高 50，左邊一顆小小的黏土茄子臉（`face-calm.webp`，打字時換成 `face-happy.webp`）。茄子只出現在這裡，不出現在別處。
- **目錄面板**：`surface` 底、圓角 24、上面一條把手。搜尋框在最上面。磚塊用紙的 `bg` 當底、`hd` 畫一個小角標，只有名字一行。
- **空狀態**：新的一張紙上只有一句話「想到什麼，先打在下面」加一顆睡著的茄子（`face-sleep.webp`）。
- **動態**：換紙是淡入淡出（150ms），不推入；面板從下面升起（220／180ms）；劃掉的行往下沉用 `dragShift` 的 150ms。減少動態時全部改淡入淡出。

## 六、最大的賭注與退路

**賭注**：把目錄藏進「點清單名」裡，第一次用的人會不會找不到其他清單？

- 名字旁邊永遠有 ⌄，這是 iOS 常見的下拉標題。
- 紙的最上面往下拉也會打開目錄（跟下拉搜尋同一個手勢）。
- 新安裝第一次打開：直接是一張空紙，不用先看目錄。多米的核心迴圈本來就是「先寫」。

**退路（方向乙）**：如果多米覺得目錄一定要是根——那就只拿「底部輸入列」這一招：首頁維持現在的列表，但最下面多一條輸入列，左邊一顆小 chip 顯示「記到：靈感 ▾」，打字就進那張。改動小很多，T1 從四步變兩步，其他全部不動。

## 七、要真機才知道的事

- 輸入列佔掉底部約 94pt，有鍵盤時紙的可見範圍剩多少（iPhone 17 直式約 874 − 62 − 336 − 94 ≈ 380pt，約 14 行）。
- 「往下拉打開目錄」會不會跟「捲到最上面」打架，要調門檻。
- 長按跟拖曳排序的把手要分開：把手只在「排序模式」出現（⋯ → 排順序），平常不畫。這是另一個推翻（現在每行右邊都有 ⋮⋮）。
- 劃掉的行沉到底下時，動畫會動到手勢 worklet，照規矩檔一定要真機。
