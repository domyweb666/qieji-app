## 中文版（直接貼）

```
幫我畫一顆茄子角色，當作手機記事 app 的空狀態插畫。

風格：扁平插畫（flat illustration），純色填色、沒有漸層、沒有陰影、沒有材質。
線條：細的深褐色描邊（接近 #3A2E42），線條粗細一致，像簡單的貼紙。
造型：茄子是圓潤的水滴形，深紫色（接近 #7D467F）；頂端一撮綠色葉子（#9DAF6A），葉子三到四瓣、很簡化。
表情：兩個小黑點當眼睛、一條短短的微笑弧線當嘴，臉頰可以加兩個淡粉色小圓。整體像在打瞌睡或放鬆，不要太興奮。
姿勢：微微歪頭，沒有手腳。
背景：純白或透明，之後要去背。
構圖：角色置中，四周留白，正方形畫布。
不要：3D、黏土質感、光澤、高光、漸層、陰影、文字、多餘的裝飾。
```

## 三、還有哪裡該放插畫（Claude 的建議）

原則：茄記的賣點是「沒有壓力」，插畫只放在**空的地方**陪人，不放在**動作之後**鼓掌。劃掉、記完、連續幾天，都不配圖，配了就變成收成計數的翻版（不做清單 #7）。

| 放哪 | 哪一張 | 為什麼 | 做不做 |
|---|---|---|---|
| 空紙 | 平靜（已有） | 第一次打開陪著他 | ✅ 已放 |
| 目錄：搜尋找不到、篩選沒有 | **疑惑**：一邊眉毛抬高、嘴巴小小的「？」感 | 「找不到含「生日」的清單」上面放一顆歪頭的，空畫面不會像壞掉 | 建議做 |
| 最近刪除：空的 | **睡著**：眼睛閉成兩條線、旁邊一個小 z | 這頁通常是空的，一顆睡著的茄子說「這裡沒事」 | 建議做 |
| App 圖示 | 平靜（線條加粗） | 桌面上認得出來 | 建議做（上面第二節） |
| 啟動畫面 | 不放 | 多米已定：一片 `page` 底，不放圖 | 不做 |
| 劃掉、記完、toast | 不放 | 鼓掌＝壓力 | 不做 |
| 目錄的色磚、每張紙的角落 | 不放 | 資訊太多（不做清單 #9） | 不做 |
| 存檔失敗、匯入錯檔 | 不放 | 錯誤訊息要人讀字，圖會搶 | 不做 |

所以總共四張：平靜（有了）、疑惑、睡著、圖示。「開心」那張先不生，目前沒有地方放（輸入列拿掉了）。

### 疑惑＋睡著，一次生兩張

```
用附上的參考圖同一顆茄子角色、同一種扁平線條風格、同一組顏色，畫兩張表情不同的：
1. 疑惑：頭往另一邊歪，一邊眉毛抬高（眉毛是一小段深褐色短線），眼睛兩點，嘴巴是小小的圓點或短短的「～」，沒有腮紅也可以。整體像在想「咦？」。
2. 睡著：眼睛閉成兩條向下的弧線，嘴巴小小的平線，臉頰腮紅保留，頭頂右上角一個小小的 z（深褐色、細線）。整體像在打盹。
兩張的身體大小、線條粗細、顏色要跟參考圖完全一樣，只有表情和頭歪的方向不同。
純白背景（之後去背），每張各一個正方形畫布，角色置中、四周留白。
不要文字、不要陰影、不要漸層、不要 3D。
```

生出來的檔名：`face-flat-puzzled.png`、`face-flat-sleep.png`，一樣跑去背（`cutout.py`：連到邊緣的白變透明、裁邊、縮 512）。接進程式時加兩處：`directory.tsx` 的兩個 `Empty`、`trash.tsx` 的 `Empty`；`Empty` 元件加一個可選的圖。
