# 茄記空紙插畫：生圖提示詞

> 多米 2026-10-31：黏土茄子先拿掉。要放就要像參考圖那種扁平、線條簡單的蔬果角色，不然不放。
> 參考圖：專注 app 底部兩顆橘色番茄（扁平填色、細深色描邊、兩點眼睛一條嘴、頭上一撮綠葉、微微歪頭）。
> 用法：丟給 ChatGPT 生圖。先生 1 張確認風格，再要成套。生出來存 `assets/img/`，去背 PNG。

## 中文版（直接貼）

```
幫我畫一顆茄子角色，當作手機記事 app 的空狀態插畫。

風格：扁平插畫（flat illustration），純色填色、沒有漸層、沒有陰影、沒有材質。
線條：細的深褐色描邊（接近 #3A2E42），線條粗細一致，像簡單的貼紙。
造型：茄子是圓潤的水滴形，深紫色（接近 #7D467F）；頂端一撮綠色葉子（#9DAF6A），葉子三到四瓣、很簡化。
表情：兩個小黑點當眼睛、一條短短的微笑弧線當嘴，臉頰可以加兩個淡粉色小圓。整體像在打瞌睡或放鬆，不要太興奮。
姿勢：微微歪頭，沒有手腳。
背景：純白或透明，之後要去背。
構圖：角色置中，四周留白，正方形畫布。
不要：3D、黏土質感、光澤、高光、漸層、陰影、文字、多餘的裝飾。
```

## 英文版（有時英文出來的風格比較準）

```
A single eggplant character for a mobile note-taking app's empty state.
Flat vector illustration, solid fills, no gradients, no shadows, no texture.
Thin uniform dark-brown outline (#3A2E42), sticker-like simplicity.
Round teardrop-shaped eggplant in deep purple (#7D467F), a small simplified green leaf cap (#9DAF6A, 3–4 lobes).
Face: two small black dot eyes, one short smiling curve for the mouth, two faint pink blush circles. Calm, sleepy, relaxed mood, not excited.
Slightly tilted head, no arms or legs.
Plain white background (to be cut out later). Centered, generous margin, square canvas.
No 3D, no clay, no gloss, no highlights, no gradients, no drop shadow, no text, no extra decoration.
```

## 要成套的話，再加這段

```
用同一個角色、同一種風格畫四張：
1. 平靜：眼睛睜開，淡淡微笑（放空紙上）
2. 開心：眼睛彎成兩條弧線，嘴巴張大一點（打字中）
3. 疑惑：一邊眉毛抬高，嘴巴小小的「？」感（找不到東西）
4. 睡著：眼睛閉成兩條線，旁邊一個小小的 z（久沒打開）
四張的大小、線條粗細、顏色完全一致。
```

## 接進 app 時

- 存成 `assets/img/face-flat-calm.png` 這類名字，去背、邊長 512 以上
- 空紙上放哪一張、放多大，先用 1 張試；代號 `emptyFace` 已拿掉，要放回來時再加
- 跟舊的黏土版（`face-*.webp`）不要混用，一個 app 一種畫風
