# 網頁預覽測手勢的小工具（2026-11-04）

只驗邏輯，驗不了手感，也驗不了 iOS 才有的問題（拖把手就是網頁正常、iPhone 壞）。

## 為什麼需要

多米的視窗最小化或窗格隱藏時（`tabs_context` 會說 hidden、截圖逾時）：

- `requestAnimationFrame` 不跑：位置表交不過去、動畫不動
- `ResizeObserver` 不跑：`onLayout` 不來
- scroll 事件大約一秒才一次：看起來捲動一片空白
- 真的點擊送不進去，要用合成的指標事件

這些都不是程式壞了。tunnel 開著時不用另開伺服器，瀏覽器直接開 `http://localhost:8081`。

## 用法

`navigate` 到 `http://localhost:8081`，然後在 `javascript_tool` 跑下面這段，等 8 秒再開始測：

```js
const html = await (await fetch('/')).text();
window.requestAnimationFrame = cb => setTimeout(() => cb(performance.now()), 16);
window.cancelAnimationFrame = id => clearTimeout(id);
Element.prototype.setPointerCapture = function () {};
Element.prototype.releasePointerCapture = function () {};
Element.prototype.hasPointerCapture = function () { return true; };
window.ResizeObserver = class {
  constructor(cb) { this.cb = cb; this.m = new Map(); this.t = setInterval(() => { const es = []; for (const [el, o] of this.m) { const r = el.getBoundingClientRect(); if (r.width !== o.w || r.height !== o.h) { this.m.set(el, { w: r.width, h: r.height }); es.push({ target: el, contentRect: r }); } } if (es.length) this.cb(es, this); }, 30); }
  observe(el) { this.m.set(el, { w: -1, h: -1 }); }
  unobserve(el) { this.m.delete(el); }
  disconnect() { this.m.clear(); }
};
window.__ev = (el, t, x, y) => el.dispatchEvent(new PointerEvent(t, { bubbles: true, cancelable: true, composed: true, pointerId: 7, pointerType: 'touch', isPrimary: true, clientX: x, clientY: y, screenX: x, screenY: y, button: t === 'pointermove' ? -1 : 0, buttons: t === 'pointerup' ? 0 : 1, width: 20, height: 20, pressure: t === 'pointerup' ? 0 : 0.5 }));
window.__drag = async (x0, y0, x1, y1, steps = 14, hold = 30) => { const el = document.elementFromPoint(x0, y0); __ev(el, 'pointerdown', x0, y0); await new Promise(r => setTimeout(r, hold)); for (let i = 1; i <= steps; i++) { __ev(el, 'pointermove', x0 + (x1 - x0) * i / steps, y0 + (y1 - y0) * i / steps); await new Promise(r => setTimeout(r, 16)); } __ev(el, 'pointerup', x1, y1); };
window.__sleep = ms => new Promise(r => setTimeout(r, ms));
delete window.__qiejiStore; // 舊的那份 app 還活著，不刪的話兩份共用資料，「新的一張」這類一次性的旗標會被舊的那份拿走
document.open(); document.write(html); document.close();
```

## 測的時候要注意

- **長按**：`pointerdown`、等 650 毫秒、`pointerup`
- **按鈕**：`document.querySelector('[aria-label="…"]').click()`
- **捲動**：改 `scrollTop` 之後要自己 `el.dispatchEvent(new Event('scroll'))`
- **看文字用 `textContent`**：進場動畫卡住時 `innerText` 是空的
- **記得**：同一頁連續合成手勢，手指沒收乾淨時下一個點擊可能失效，換一次新頁再測
- **控制台會多一個 `startTime` 的錯誤**：舊的那份 app 造成的，不用管
- **測完**：`resize_window` 回 desktop、關掉分頁（不然網頁的 `[perf]` 會一直灌進跑 tunnel 的終端機，蓋掉手機的訊息）
