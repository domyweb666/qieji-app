# 操作清單（待驗）：組塊 D 批次（D2 拖疊成資料夾＋D3 從資料夾拖出來）

> 2026-11-02 產出。D2、D3 都做完了，整塊一起玩。照順序玩，哪一條怪怪的就停下來，照條號回報。
> 開法：tunnel 照舊，手機重新載入（純 JS）。紙要有六張以上、至少一個資料夾比較好玩。
> 這份清單 2026-11-02 晚加了第三段（照 Apple 使用手冊補的三件事），第 12～19 條裡跟「移出資料夾」文字選項有關的已經不適用（選項拿掉了）。
> 先試第 0 條：點清單名（紙最上面的大字）→ 沒反應；⋯ 選單按「改名字」才能改（多米 2026-11-02 晚改的）。

## 一、D2 拖疊成資料夾（全部是拖，網頁預覽測不到）
- [ ] 0. 點清單名沒反應；⋯ →「改名字」→ 清單名可以打字
- [ ] 1. 目錄長按一張紙，拖著停在另一張紙磚的正中間不動約半秒 → 底下那張放大一點、震一下
- [ ] 2. 這時放手 → 兩張變成一個資料夾，站在底下那張的位置；**資料夾不打開**（2026-11-02 錄影後照 iOS 改），名字叫「新資料夾」；點開來看：底下那張排第一、拖的那張第二
- [ ] 3. 拖一張紙停在資料夾磚正中間約半秒 → 資料夾磚放大；放手 → 紙進資料夾最後面，目錄少一格
- [ ] 4. 磚放大之後把手指移開 → 磚縮回去；這時放手 → 照一般換位，沒有疊
- [ ] 5. 拖著停在兩張磚中間、或磚的邊邊約 0.2 秒 → 其他磚才讓位；放手換到那裡
- [ ] 6. 拖著一路滑過好幾張磚不停 → 經過的磚不會一直跳；停下來才讓位
- [ ] 7. 拖資料夾磚停在別張紙中間 → 不會放大、不會疊；停久一點照樣讓位換位
- [ ] 8. 拖到螢幕右邊緣停一下 → 翻到下一頁；在那頁停在某張磚正中間 → 一樣疊得起來
- [ ] 9. 疊完關掉 app 再開 → 資料夾和裡面的紙都在；疊錯的用 D1「移出資料夾」拆得回去
- [ ] 10. 換位的手感：停一下才讓位，你覺得太慢、太快還是剛好？（0.2 秒、半秒都能調）
- [ ] 11.（選做）打開「減少動態」→ 底下那張直接變大、不跑動畫，照樣疊得起來

## 二、D3 從資料夾拖出來（全部是拖，網頁預覽測不到）
- [ ] 12. 打開一個有三張以上的資料夾，長按裡面一張不動 → 跳選單（跟 D1 一樣）
- [ ] 13. 長按後一拖 → 選單收起，那張浮起來跟著手指，框裡那格變空
- [ ] 14. 拖到資料夾框外面 → 框變淡、震一下；放手 → 資料夾收起，那張出現在目錄、排在資料夾後面一格
- [ ] 15. 拖到框外再拖回框裡 → 框變回來；在框裡放手 → 那張滑回原位，資料夾裡什麼都沒變
- [ ] 16. 資料夾只剩一張時把它拖出框外放手 → 資料夾不見，那張站在資料夾原本的位置
- [ ] 17. 在資料夾裡點一張（不長按）→ 照舊換到那張紙、目錄收起
- [ ] 18. 拖出來之後關掉 app 再開 → 那張在目錄、不在資料夾
- [ ] 19.（選做）打開「減少動態」→ 浮起、滑回不跑動畫，照樣拖得出來

## 三、照 iOS 補的（多米 2026-11-02 晚回報第 2～4 點）
- [ ] 20. 目錄格子的空白處（磚和磚之間、最後一張下面）按住不放 → 全部磚開始抖
- [ ] 21. 抖動中點一下格子的空白處 → 停止抖動
- [ ] 22. 抖動中點資料夾磚 → 資料夾打開，裡面的紙也在抖；手指按著一張一動就拿起來，拖到框外放手 → 拿出來、排在資料夾後面
- [ ] 23. 不抖的時候打開資料夾，長按裡面一張 → 選單只有顏色、改名字、刪除（沒有「移出資料夾」）
- [ ] 24. 抖動中點一般的紙磚 → 不換紙（照舊）；點磚照常不會誤進抖動
- [ ] 25. 目錄長按一張紙 → 選單有「釘選」（已釘的寫「取消釘選」）；釘滿兩張再釘 → 問要換掉哪一張
- [ ] 26. 目錄長按選單沒有「放進資料夾…」；要做資料夾就拖疊（第 1～3 條）

## 四、D4 拖曳照 iOS（多米 2026-11-02 晚選的三件；這段取代第 12～16 條的「拖出框外放手排在資料夾後面」）
- [ ] 27. 抖動中拖一張紙停在資料夾磚上：約半秒資料夾磚放大；再停約半秒 → 資料夾自己打開，紙還在手上
- [ ] 28. 資料夾打開後把紙移進框裡、停在兩張中間一下 → 讓位；放手 → 放在那個位置；關掉 app 再開還在那裡
- [ ] 29. 資料夾彈開後不進框、直接放手 → 紙回原位，什麼都沒變
- [ ] 30. 打開資料夾，拖裡面一張在框裡移動 → 其他張讓位；放手 → 換到那裡（資料夾裡換順序）
- [ ] 31. 從資料夾拖一張出框外停一下 → 資料夾收起，紙還在手上；拖到目錄某一格停一下讓位，放手 → 就在那一格
- [ ] 32. 從資料夾拖出來後停在別張紙正中間半秒 → 放手疊成新資料夾；停在別的資料夾磚上 → 放手放進去
- [ ] 33. 從資料夾拖出來後拖到右邊緣停一下 → 翻頁，放到下一頁
- [ ] 34. 拖出框外、資料夾還沒收起就放手 → 紙排在資料夾後面
- [ ] 35. 資料夾只剩一張時把它拖出來放到別格 → 資料夾不見（2026-11-02 起剩一張的資料夾只會因為刪除出現，見第 43 條）
- [ ] 36.（手感）資料夾彈開要停多久、離開框要多久才收起，太快還是太慢？（各 0.5 秒、0.35 秒，能調）

## 五、錄影回報修正（2026-11-02，紀錄在 `.vibe/真機回報-影片-2026-11-02.md`）
- [ ] 37. 抖動中點資料夾磚（正常點，不用特別小心手指不動）→ 資料夾打開，裡面的紙也在抖；磚不會閃一下
- [ ] 38. 抖動中按住一張磚拖 → 照樣拿得起來（門檻從 6 點改 10 點，手感有沒有變鈍？）
- [ ] 39. 不抖的時候打開資料夾，按住一張 → 跳選單；這時手指拖動 → 選單收掉、那張被拿起來，不會選單和拖同時在畫面上
- [ ] 40.（除錯用）開 tunnel 的終端機開著，重做一次「打開資料夾 → 拖一張出框 → 等資料夾收起 → 放到目錄某一格」。不管有沒有跑回去，把終端機裡 `[茄記除錯]` 開頭的幾行複製給 Claude

- [ ] 41. 點開任何一個資料夾 → 框在畫面中間、名字是框上面的大字（點名字可以改）；拖進拖出、框裡換順序照樣對得準（框換位置了，第 27～35 條順便再看一次）
- [ ] 42. 長按資料夾 →「改名字」→ 資料夾打開、名字可以直接打
- [ ] 43. 有兩張的資料夾，拖一張出框 → 資料夾收起時，那格就變回剩下那張；放到別格放手 → 目錄裡沒有資料夾了，剩下那張站在原本資料夾那格。關掉再開一樣
- [ ] 44. 接上一條，拖出來的那張不放別格、直接疊回剩下那張的正中間 → 又變回資料夾，站在原本那格
