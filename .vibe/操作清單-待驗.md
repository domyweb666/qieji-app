## 一、建資料夾、放進去
- [ ] 1. 打開目錄，長按一塊紙磚 → 選單有「改名字」「放進資料夾…」「刪除」「編輯目錄」
- [ ] 2. 點「放進資料夾…」（這是第一個資料夾）→ 那張紙的位置變成資料夾、資料夾自己打開，上面寫「新資料夾」而且可以直接打字；打一個名字（例如「工作」）
- [ ] 3. 點資料夾外面 → 收起；目錄上那格是資料夾磚：上面是「工作」，下面一個小色塊（那張紙的顏色）
- [ ] 4. 再長按另一張紙 →「放進資料夾…」→ 跳出清單：「工作」「新資料夾」「取消」；點「工作」→ 那張從目錄不見，資料夾磚多一個小色塊
- [ ] 5. 放到五張以上 → 資料夾磚只畫四個小色塊，後面寫「+1」（或更多）

## 二、打開、改名、換紙
- [ ] 6. 點資料夾磚 → 在目錄上面打開，看得到名字和裡面的紙（放進去的先後順序）
- [ ] 7. 點名字改成別的，點外面收起 → 資料夾磚上的名字跟著改；把名字整個刪光再點外面 → 變回原本的名字
- [ ] 8. 打開資料夾點裡面一張 → 換到那張紙、目錄收起；再開目錄 → 資料夾磚有框（正在看的紙在裡面）
- [ ] 9. 長按資料夾磚 → 選單「改名字」「編輯目錄」；點「改名字」→ 資料夾打開、名字可以打
- [ ] 10. 長按資料夾磚後一拖 → 跟紙磚一樣抖動、拖得動、其他磚讓位；拖到邊緣停一下會翻頁

## 三、移出、刪除、搜尋
- [ ] 11. 打開資料夾，長按裡面一張 → 選單有顏色、「改名字」「移出資料夾」「刪除」（沒有編輯目錄）；點「移出資料夾」→ 那張回到目錄、排在資料夾後面一格
- [ ] 12. 資料夾裡只剩一張時把它移出 → 資料夾不見，那張站在資料夾原本的位置
- [ ] 13. 資料夾裡的一張刪掉 → 到最近刪除還原 → 回到資料夾裡
- [ ] 14. 在搜尋打資料夾裡某張紙的字 → 直接列出那張紙（不出現資料夾）
- [ ] 15. 點「新的一張」→ 排在目錄最後面，不會跑進資料夾

## 四、存起來、上 iCloud
- [ ] 16. 從多工畫面把 app 滑掉再打開 → 資料夾、名字、裡面的紙和順序都在
- [ ] 17. 改完資料夾等 10 秒 → 「檔案 › iCloud 雲碟 › 茄記」裡 `layout.json` 的修改時間更新
- [ ] 18.（選做，🔴 會刪掉手機上的茄記資料，跟 C2 第 7 條一樣先數檔案）刪 app 重裝 → 紙回來後資料夾也回來，名字、裡面的紙一樣
