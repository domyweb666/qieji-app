## 結論

**試過了，抓得到，我建議用 Limrun。** 拿今天的拖把手當考題：壞掉的版本跟你手機上一樣拖不動，3 次都留在原位；修好的版本 3 次都換了順序。

- 這次花的：0 元。EAS 建置 1 次（本月 4／15）。Limrun 約 43 點（模擬器一共開了約 21 分半，照分鐘數算），一次性的 120 點還剩約 77 點。

- 抓不到的還是抓不到：手感、震動、120Hz。這套只替你先擋掉功能壞掉的版本，順不順還是要你的手來定。

## 目錄拖磚：原因和修法

原因跟今天的拖把手同一類。選單開著時，程式把整個目錄的圖層順序調到底部把手上面；選單一關就調回來。手指一拖，選單收起，順序跟著換，iOS 就把整個目錄拆下來重裝，手指正在拖的手勢當場被取消。網頁的圖層順序是另一套，不會拆，所以網頁一直正常。

修法只動 `DirPanel.tsx` 一個檔案：把手固定排在目錄前面，順序不再切換。

同一份考題，修前修後對照：

| | 拖到哪裡被取消 | 磚有沒有換位置 |
|---|---|---|
| 修之前 | 手指才走 22 點就被取消 | 沒有 |
| 修之後 | 沒被取消，走到 184 點才放手 | 有，搬到右邊那格 |

回頭驗了會被影響的地方，都正常：

- 按住磚跳選單，暗幕蓋得到把手；選單開著點把手，只收選單
- 抖動中點把手，只停止抖動
- 疊成資料夾、打開資料夾；資料夾開著點把手，只收資料夾
- 沒有選單時點把手或往下撥，目錄收起
- 單元測試 150 條、`tsc`、lint、裸數字檢查都過

還有一個小差別：VoiceOver 會先念把手「收起目錄」，再念目錄內容，以前順序相反。這點沒開 VoiceOver 實測。

修法已套回 `perf/feel-engine`（`1058605`），只改 JS，不用重建。這些都是模擬器上的結果，真機還沒看。

## 抓得到、抓不到

實測抓得到：手勢沒反應、結果不對、上下順序、鍵盤有沒有收、字有沒有跳。Limrun 文件寫閃退時會回報原因，這次沒遇到閃退，還沒驗過。

抓不到：

- iCloud、桌面小工具、控制中心
- 效能數字：雲端機器的快慢不能代表 iPhone

### 目錄拖磚的技術細節

- 已提交 `1058605`（基於 `7ccedc3`）。`Directory` 根節點原本 `(!!menu || !!openEntry?.folder) && st.above`（`zIndex: 1`）。`dragStartGrid` 裡的 `setMenu(null)` 讓兄弟順序從 `[panel, grab, Directory]` 變回 `[panel, Directory, grab]`，Fabric 把 `Directory` Remove＋Insert，底下的 `RNGestureHandlerDetector willMoveToWindow:nil` → `detachAllHandlers`，進行中的 pan 收到 cancel。
- 記錄對照：修前 `lift dx=18.3` → `dragStartGrid` → `deactivate canceled=true dx=22`；修後同一步 `deactivate canceled=false dx=184`。這組 A/B 證實問題出在這個順序切換；RN 內部 Remove＋Insert 那段是讀原始碼推的，沒有下原生斷點看。
- 原本 `above` 的註解放錯位置，留在 `parked` 那行，修法一起拿掉。`grep zIndex src` 目前只剩 `Overlay.tsx` 的提示條（固定值）和 `Paper.tsx` 的 `held`（已包進自己一層）。
- 抖動中拖磚要疊成資料夾：互換只要停 100 毫秒，測試腳本慢慢走會先換，要一步跳到正中間、手指微動停住（`tile-final.mjs`）。
- 坑已寫進 `.vibe/規矩檔.md`，`.vibe/送審前總驗.md` 第 19 條已註明，`.vibe/代決清單.md` 記了 VoiceOver 念的順序變了。

### 踩到的坑

- 這台 Windows 上 `lim ios` 每個指令都等 15 秒才放棄背景連線（`Could not start WebSocket daemon`），扣的都是模擬器分鐘。測試改用 `@limrun/api` 的 `Ios.createInstanceClient`。
- `lim run` 會把 skill 寫進專案、上傳原始碼建置並扣點，不要用。貼文裡的 `@limrun/mcp-server` 在 npm 是 404，官方是 `claude mcp add --transport http limrun https://mcp.limrun.com/mcp`。
- 第一次開開發版會跳開發選單，要點 Continue、再點 Close。
- 開發版的齒輪浮鈕蓋在 ⋯ 和 ✓ 上，用座標或 label 點「完成，收起鍵盤」會開到開發選單。要測 ⋯ 先在開發選單關 Tools button，或改用 Release 建置。
- 提示條只停 3.5 秒，一來一回讀畫面就錯過，復原要跟滑動放在同一批 `performActions`。
- 磚的 label 是「名字，顏色」，行的 label 就是字。對比上下順序直接比 `frame.y`。
- ffmpeg 的 crop 在 yuv420 上會把高度捨成偶數，切格會錯位，要先 `format=gray` 再 crop（`exact=1`）。
- `expo-doctor` 這次報 8 個套件小版本落後（`react-native-safe-area-context` 5.10.1→~5.11.1、`expo` 58.0.22→~58.0.23 等）。規矩是建置前要 `--fix`，這次為了跟多米手機上的開發版同一份版本，刻意沒修。下次重建開發版前要處理。
