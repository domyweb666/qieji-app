# 茄記 1.0.0 送審步驟

> 2026-11-01。照順序做，做完一步打勾。要你在 Apple 網站上按的都是你按，我不碰你的帳號。
> 指令都在終端機面板跑，**先切到專案資料夾**：`cd E:\茄記\qieji-app`

## 一、在 App Store Connect 建 app（約 5 分鐘）

- [ ] 打開 https://appstoreconnect.apple.com → 我的 App → 左上 ＋ → 新增 App
- [ ] 平台：iOS
- [ ] 名稱：茄記（被別人用走的話，改「茄記：想到就記」之類，最多 30 字）
- [ ] 主要語言：繁體中文
- [ ] 套件 ID：選 `org.domyweb.qieji`
- [ ] SKU：`qieji-ios`（自己看的編號，隨便取不重複就好）
- [ ] 使用者存取權限：完整存取權
- [ ] 建好後到左邊「App 資訊」，把「Apple ID」那串數字（例：6740000000）**貼給我**，我寫進 `eas.json`，上傳時才知道要傳到哪個 app

## 二、正式版建置＋上傳（約 30 分鐘，大多在等）

- [ ] 我把 Apple ID 寫進 `eas.json`、commit 之後，你跑：

```
npx eas-cli@latest build --profile production --platform ios --auto-submit
```

- [ ] 中途會問 Apple 帳號登入、要不要讓 EAS 管理憑證：都選是（跟建開發版時一樣）
- [ ] 跑完會自動上傳到 App Store Connect。Apple 處理要 10～30 分鐘，好了會寄信

這次建置會一起換上：方格紙黏土茄子圖示、只支援 iPhone、正式版的 iCloud。

## 三、自己先用 TestFlight 裝一次（約 30 分鐘）

開發版和正式版是同一個 app，裝了正式版就會取代開發版。

- [ ] App Store Connect → 茄記 → TestFlight → 內部測試 → 新增群組，把自己加進去
- [ ] iPhone 裝「TestFlight」app，收信接受邀請
- [ ] **裝之前先數**：「檔案 › iCloud 雲碟 › 茄記」裡的 `.json` 數量跟你的紙（含最近刪除）一樣多
- [ ] 數量對了 → 刪掉開發版 → 從 TestFlight 裝茄記 → 打開等十秒 → 紙全部回來（這就是 D2）
- [ ] 照 `.uiux/08-上架.md` 第一節 L2～L14 逐列跑，結果回給我

**D2 沒過（紙沒回來）就先停**，不要送審，跟我說看到什麼。

## 四、截圖（約 15 分鐘）

- [ ] 在 TestFlight 裝的正式版上截 3～5 張：一張紙、目錄、按 ＋ 記一行、深色模式、主畫面小工具
- [ ] 截圖丟給我。你的 iPhone 17 截出來是 6.3 吋的尺寸，Apple 要 6.9 吋（1320 × 2868），我幫你放大成剛好的尺寸
- [ ] 只上 iPhone，不用準備 iPad 截圖

## 五、在 App Store Connect 填資料（約 20 分鐘）

文案草稿在 `.vibe/送審文案-1.0.0.md`，可以直接貼。

- [ ] **App 資訊**：副標題、類別（主要：生產力工具）、年齡分級問卷（全部選「無」，會是 4+）
- [ ] **價格與銷售地區**：免費；地區先全選或只選台灣，你決定
- [ ] **App 隱私**：隱私權政策網址；資料蒐集選「不，我們不會從此 App 蒐集資料」
- [ ] **1.0 版本頁**：截圖、宣傳文字、描述、關鍵字、支援網址、版權（`2026 陳多米`）
- [ ] **建置版本**：選剛剛上傳的那個
- [ ] **App 審查資訊**：不需要登入（取消勾選「需要登入」）；聯絡人填你的；備註貼文案檔裡的「給審核人員的備註」
- [ ] **版本發佈**：建議選「手動發佈此版本」，過審後你自己按上架

## 六、送出

- [ ] 右上「新增以供審查」→ 送出
- [ ] 審核通常一兩天，結果會寄信。被退的話把信的內容貼給我

## 送出前還缺的

- [ ] **隱私權政策網址、支援網址**：Apple 規定一定要有。文案檔裡有隱私權政策全文，貼到一個公開網頁（例如 Notion 公開頁面），兩個網址可以用同一頁
- [ ] 公開聯絡信箱：文案檔裡寫「（換成你的信箱）」的地方
