## 第 1 步：同意 Apple 的新合約（3 分鐘）

1. 打開 https://developer.apple.com/account 登入
2. 最上面如果有黃色或紅色的合約提示，點進去同意。沒有就跳過

沒同意的話第 3 步會卡住（10/31 踩過）。

## 第 2 步：在 App Store Connect 建 app（5 分鐘）

1. 打開 https://appstoreconnect.apple.com ，點「App」
2. 左上角 ＋ →「新增 App」，照下面填：

| 欄位 | 填什麼 |
|---|---|
| 平台 | iOS |
| 名稱 | 茄記（被用走了就填「茄記：想到就記」，再跟我說） |
| 主要語言 | 繁體中文 |
| 套件 ID | 下拉選 `org.domyweb.qieji` |
| SKU | `qieji-ios` |
| 使用者存取權限 | 完整存取權 |

3. 建好後點左邊「App 資訊」，往下找「一般資訊」裡的「Apple ID」，是一串 10 位左右的數字
4. 把那串數字貼給我。我寫進設定檔、提交，跟你說可以了才往下

## 第 3 步：建正式版並上傳（你操作 5 分鐘，等 30 分鐘）

1. 在這個 app 下面的終端機面板貼這行，按 Enter（資料夾要是 `E:\茄記\qieji-app`）：

```bash
npx eas-cli@latest build --profile production --platform ios --auto-submit
```

2. 它會一題一題問，照這樣答：

| 它問 | 你答 |
|---|---|
| 要不要登入 Apple 帳號 | Y，輸入 Apple ID、密碼，再輸入手機跳出來的驗證碼 |
| 要不要產生 Distribution Certificate | Y |
| 要不要產生 Provisioning Profile（會問幾次，app、小工具、控制中心各一個） | 每次都 Y |
| 要不要產生 App Store Connect API Key | Y |
| 其他 Yes／No | 按 Enter 用預設值；看不懂就截圖給我 |

3. 出現建置網址就可以等了，建置在雲端跑。這次會用掉 1 次免費額度（每月 15 次）
4. 建好會自動上傳，Apple 處理完會寄信。信到了再做第 4 步

失敗的話把最後 20 行貼給我。

## 第 4 步：用 TestFlight 裝到手機（20 分鐘）

這步不是總驗。描述裡寫了「刪掉重裝，紙會自己回來」，這件事還沒在正式版上跑過，而且你的紙也是第一次搬到正式版，所以這步我建議不要省。

先把自己加進測試：

1. App Store Connect → 茄記 → 上面的「TestFlight」
2. 左邊「內部測試」旁的 ＋，群組名稱打「自己」，把你的帳號勾進去，建置版本選剛上傳那個
3. iPhone 到 App Store 裝「TestFlight」，打開收到的邀請信，點「開始測試」

裝上去，順便清掉測試紙：

4. 在 TestFlight 按「安裝」或「更新」。正式版會直接取代開發版，紙都留著。如果它要你先刪開發版，**先別刪**，截圖給我
5. 打開茄記，紙都在、⋯ 裡沒有「塞到上限」，就對了
6. 把 1000 行那張和其他測試紙丟掉：⋯ →「刪除這張」→ 到目錄最下面「最近刪除」→ 點那張 →「永久刪除」。這個刪了就沒有了，確定是測試紙才按。不清掉的話，它們會跟著 iCloud 回來

確認紙回得來：

7. 等一分鐘，打開「檔案」app → iCloud 雲碟 → 茄記
8. 數檔名是一串亂碼的 `.json`（`gone.json`、`layout.json` 不算），應該跟你的紙一樣多，放在最近刪除的也算，沒動過的「從這裡開始」不算
9. 數量對了，才把茄記從手機刪掉，再從 TestFlight 重新安裝
10. 打開等十秒。可能先看到「從這裡開始」那張，等一下你的紙會回來

數量不對，或紙沒回來，就停在這裡，什麼都別刪，跟我說你看到什麼。

最後花三分鐘走一圈：按 ＋ 記一行、往右滑劃掉、往左滑刪掉再按復原、換一張紙、開目錄、看主畫面小工具有沒有更新、按控制中心的「記一行」。怪的講給我聽，沒怪就往下。

## 第 5 步：拍截圖（15 分鐘）

1. 照文案檔「截圖要用的紙」開一張展示紙和幾張空的磚，你真的紙別入鏡
2. 淺色模式截：一張紙（有一行劃掉）、按 ＋ 正在打字、目錄；深色模式截：一張紙；再截主畫面上的茄記小工具
3. 截圖傳到電腦，放在同一個資料夾

你的 iPhone 17 截出來是 1206 × 2622，Apple 現在收這個尺寸，不用放大。第 7 步上傳時如果它要別的尺寸，把截圖丟給我，我轉成它要的。

## 第 6 步：把隱私權政策和支援頁放上網（10 分鐘）

Apple 規定兩個網址都要有，別人不用登入就要看得到。

1. 告訴我要公開的聯絡信箱，我填進文案檔
2. 在 Notion 開一個新頁面，貼上文案檔的「隱私權政策」，再開一頁貼「支援頁」
3. 每一頁按右上「分享」→「發布」→ 打開「發布到網路」→ 複製網址
4. 開瀏覽器的無痕視窗貼網址，確認看得到

## 第 7 步：在 App Store Connect 填資料（30 分鐘）

**左邊「App 資訊」**

| 欄位 | 填什麼 |
|---|---|
| 副標題 | 文案檔 |
| 主要類別／次要類別 | 生產力工具／工具程式 |
| 內容版權 | 不包含第三方內容 |
| 年齡分級 | 按「編輯」，每一題照實答，茄記全部都是「無」或「否」。結果應該是 4+，不是的話截圖給我 |

**左邊「定價與銷售地區」**

- 價格選免費（0 元）
- 銷售地區我建議全選，再取消「中國大陸」和歐盟 27 國

原因：中國大陸要 ICP 備案編號；賣歐盟要向 Apple 申報是不是「交易者」，是的話地址和電話會公開在歐盟的商店頁。之後想賣再加回來就好。如果畫面還是要你回答交易者那題，截圖給我，這題是法律認定，要你自己定。

**左邊「App 隱私權」**

1. 「隱私權政策網址」貼第 6 步的網址
2. 按「開始」，選「否，我們不會從此 App 蒐集資料」
3. 按「發布」
4. 無障礙標籤先都不要勾，這項是選填，勾了就要真的都做得到

**左邊「1.0 準備提交」那頁**

| 欄位 | 填什麼 |
|---|---|
| 截圖 | 第 5 步那幾張，拖進 iPhone 那格，順序照文案檔 |
| 宣傳文字、描述、關鍵字 | 文案檔 |
| 支援網址 | 第 6 步支援頁的網址 |
| 行銷網址 | 留空 |
| 版權 | `2026 陳多米` |
| 建置版本 | 按 ＋，選剛上傳那個 |
| 登入資訊 | 取消勾選「需要登入」 |
| 審查聯絡資訊 | 你的姓名、電話、信箱（只有 Apple 看得到） |
| 備註 | 文案檔「給審核人員的備註」 |
| 版本發佈 | 手動發佈此版本 |

每一頁填完按右上「儲存」。

## 第 8 步：送審（1 分鐘，等一兩天）

1. 右上「新增以供審查」→ 下一步一路看過 →「提交至 App 審查」
2. 結果會寄信，通常一兩天
3. 被退的話，把信的內容或 App Store Connect 裡 Apple 寫的那段貼給我，我看要改程式還是改文案。被退很常見，改完再送就好

## 第 9 步：過審後上架

1. 收到「等待開發者發佈」的通知，自己挑時間，到那一版按「發佈此版本」
2. App Store 上出現可能要等一陣子，搜尋得到會更晚，最多可能一天。先用商店連結分享
3. 第 1、7、30 天要看什麼在 `.uiux/08-上架.md` 第五節，看到評論有「紙不見」「閃退」就貼給我

## 之後要改版怎麼辦

跟我說要改什麼，改完重跑第 3 步的指令，再到 App Store Connect 新增版本、選新的建置版本、填「這個版本的新功能」，送審。

開發版已經被正式版取代。要回來邊改邊看手感時，要再建一次開發版（同一個 app，又會取代正式版），紙都在，所以我建議測試機上就這樣換來換去沒關係。
