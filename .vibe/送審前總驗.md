# 送審前總驗（照現在的 app 從頭走一遍）

> 2026-11-04 整理。舊的 `操作清單-待驗.md` 累積的條目，作廢的劃掉、其他併進這裡，你只要測這一份。
> **開法**：在 `E:\茄記\qieji-app` 跑 `npx expo start --tunnel`，手機把茄記從多工畫面滑掉再開。上次重建開發版之後只改過 JS，不用重建。
> **準備**：開五、六張測試紙來拖、來刪，免得把你真的排列弄亂，測完丟掉就好。第八節要用那張 1000 行的測試紙，最後一條才刪；已經沒有的話，開一張新的按 ⋯ 最下面「（開發）塞到上限」。
> **★ 是最要緊的**，時間不夠就先測 ★。
> **手感**：太慢、太快、卡，隨時講，不用等測完。開發版本來就比正式版慢，卡不卡最後要看正式版。

## 一、記

- [ ] 1. ★ 按右下 ＋ → 輸入框貼著鍵盤升起，提示字「記一行」，後面的紙變暗。打字按換行鍵 → 那行出現在紙最上面、亮一下，框清空、鍵盤不收，可以接著打。打很長一段 → 框跟著長高。捲到紙很下面再記一行 → 畫面捲回最上面，看得到新的那行
- [ ] 2. ★ 打到一半離開輸入框，字都不會丟：按框右邊 ✓、或點紙上的空白處 → 字變成最上面一行，框和鍵盤收起；點某一行 → 字先記下，游標進你點的那一行，畫面不跳
- [ ] 3. ★ 被打斷：按 ＋ 打幾個字，馬上回主畫面，再把茄記從多工畫面滑掉重開 → 剛打的字變成一行，還停在這張紙。點進一行改幾個字，做同一件事 → 改的字也在

## 二、一行字

- [ ] 4. 點一行 → 游標落在你點的地方，原地改字；右上有茄紫 ✓，按了收鍵盤。上下捲動時手指碰到字，不會跳鍵盤
- [ ] 5. 在行裡按換行鍵 → 同一則分段、那則長高，左右滑和拖小點點都是整則一起動。貼上一段有好幾段的字 → 整段留在同一則。游標在行首按刪除鍵 → 併回上一行（兩行都沒劃掉才會併）
- [ ] 6. ★ 往右滑過一段 → 震一下，放手劃掉：字變淡、加刪除線、留在原位；再往右滑一次 → 恢復。往左滑過一段 → 那行淡出、下面的行滑上來，下面跳「已移到最近刪除」和「復原」；按復原回到原位
- [ ] 7. 按住一行不動 → 選單：劃掉（已劃掉的寫恢復）、搬到…、複製、刪除；後面霧掉、右下 ＋ 收起；點外面收起、＋ 回來。按「複製」→ 跳「已複製」
- [ ] 8. ★ 拖右邊六個小點 → 那行黏著手指、其他行讓位跟得上，放手滑進新位置不抖。只按不拖放手 → 不跳選單。點一下小點 → 進那行改字。從小點那裡左右滑 → 照樣劃掉、刪除
- [ ] 9. 按住一行 →「搬到…」→ 目錄升起，上面寫「把「那行的字」搬到」，搜尋框寫「搜尋清單」，磚一排四個；點一張 → 面板收起、你留在原本這張，跳「已搬到「那張」」，到那張看，那行在最上面。再搬一次，這次按右上 ＋ → 搬進新的一張

## 三、⋯ 選單

- [ ] 10. 右上 ⋯、右下 ＋ 是玻璃材質（＋ 是茄紫）。點 ⋯ → iPhone 系統選單，最上面一排九個顏色：點一色 → 紙換色、震一下。按「改名字」→ 左上膠囊變輸入框，打完收鍵盤變回膠囊、名字換了、字頂沒被切掉
- [ ] 11. 按「釘選」→ 跳「已釘選」，切換清單的「釘選」組裡有它，目錄的磚有小圖釘、磚不移位。釘滿 5 張再釘 → 問「已釘滿 5 張／要換掉哪一張？」：選一張 → 換掉，提示條有「復原」，按了回到原本那 5 張；按取消 → 什麼都不變
- [ ] 12. 「分享」→ 系統分享表，按取消不跳任何訊息。「複製全文」→ 跳「已複製」，貼到別的地方看：清單名、每一行有編號，劃掉的行帶「（劃線）」
- [ ] 13. ★ 找一張紙劃掉兩三行 → ⋯ →「清掉劃掉的行」：那幾行不見，跳「已把 N 行移到最近刪除」和「復原」。按復原 → 回到原本的位置，最近刪除沒有多一份。再清一次，這次先按 ＋ 記一行再按復原 → 剛記的那行還在。有劃掉的行時還有「全部恢復」→ 全部變回沒劃掉
- [ ] 14. 找一張釘選的測試紙 → ⋯ →「刪除這張」：換到最近改過的另一張，跳「已移到最近刪除」；按復原 → 回來、還是釘選的，目錄裡站回原本那格

## 四、切換清單

- [ ] 15. ★ 點左上清單名 → 面板從下面升起、貼齊底部：最上面「＋ 新的一張」，一條線，「釘選」「最近」兩組（每項小方磚＋名字，正在看的打勾），最下面「管理所有清單」。點上面露出的紙、或往下撥上緣 → 收起。紙上左右滑不會換張，往下拉不會開目錄
- [ ] 16. 點別張 → 面板收起、換到那張；點正在看的 → 只收起；點一張後馬上點外面 → 還是換過去。開過幾張再看：「最近」照開的先後排、最多 5 張、不跟「釘選」重複（這台開過的不滿 5 張時，用最近改過的補）
- [ ] 17. ★ 點「新的一張」→ 面板收起 → 一張空的黃色紙 → 輸入框和鍵盤馬上升起，打字按換行鍵就記進去。到目錄看：它在第一個空位，沒有空位就在最後一格。再點一次「新的一張」什麼都不打，從切換清單換到別張 → 不留下空紙

## 五、目錄

- [ ] 18. 點「管理所有清單」→ 面板收完、目錄升起：上面搜尋框寫「搜尋」、右邊一顆 ＋。磚一排四塊：紙的顏色＋中間一個字、名字在下面（太長變…）；正在看的一圈茄紫，釘選的有小圖釘，黑豆那種深色磚是白字。資料夾磚一樣大，裡面小方塊是每張的顏色和字。點上面露出的紙、或往下拉頂端把手 → 收起。點一張 → 那塊磚放大鋪滿，接著露出那張紙，不閃
- [ ] 19. 按住一張不動 → 磚浮起，下面選單：一排顏色、改磚上的字、釘選、刪除；放手選單留著、磚沒移位；點外面只收選單、目錄不收。點一色 → 磚馬上換色。「改磚上的字」打一個字或 emoji 按「好」→ 磚上換字，名字不變；清空按「好」→ 回到名字第一個字；打兩個字 → 跳「只能打一個字」，按「知道了」回到輸入框、字還在。跳出選單後手指不放、拖一段 → 選單收起、進抖動、磚跟著手指
- [ ] 20. 按住格子空白處 → 全部抖：紙磚左上有「−」（資料夾沒有），右上「完成」。點空白處、按完成、點上面露出的紙 → 都是停止抖動，目錄不收。抖動中點紙磚 → 不換紙；按住一張 → 放大、「−」不見，放手縮回
- [ ] 21. 抖動中點「−」→「要刪除「X」嗎？」：取消 → 沒變；刪除 → 進最近刪除、那格空著、別張不往前補，提示條按「復原」→ 回到那格。「−」好不好點，拖磚時會不會誤點到，順便看
- [ ] 22. ★ 抖動中拖一張蓋到別張偏邊的地方停一下 → 兩張互換，其他不動，手指不放可以繼續換。拖著經過 B 再停到 C 放手 → 只有 C 跟你對調，B 回自己那格。拖回原本那格停一下 → 整頁回到拿起前。拖到這頁下面空的格子 → 放手就停在那格，上面空著、原本那格空著；一頁最後面的空格放手後自動不見
- [ ] 23. ★ 抖動中拖一張蓋到別張正中間停一下 → 底下那張放大，手稍微晃不會取消；放手 → 縮進去變「新資料夾」、不打開、彈一下，站在底下那張的位置，原本那格空著。手移開再放 → 不疊。拖到資料夾磚正中間放手 → 進最後面、資料夾不打開。拖資料夾磚蓋到別張中間 → 不會疊
- [ ] 24. 拖到螢幕左右邊緣（看手指，抓磚的哪邊都一樣）停一下 → 翻頁，磚還在手上，放進那頁的空格或互換都行，不閃退。最後一頁再往右 → 開新的一頁；新頁拖空 → 放手後收掉、頁點少一個。兩頁以上時：不抖時左右撥整頁翻、頁點跟著亮；抖動中在空白處撥也翻得動
- [ ] 25. 點資料夾磚 → 打開：後面霧很重，框是液態玻璃、只包三欄，名字靠左跟第一欄對齊。點名字打字改名（注音也打打看）→ 順、字沒掉；點框外收起 → 磚上是新名字。點裡面一張 → 放大打開那張
- [ ] 26. 長按資料夾磚 → 沒有選單，直接抖動。抖動中點資料夾（手稍微晃也算）→ 打開，裡面也抖、紙有「−」。不抖時在資料夾裡按住一張 → 選單跟第 19 條一樣，拖一段才拿起來；稍微動一下就放手 → 留在原位、資料夾還開著
- [ ] 27. 資料夾裡拖一張到別格放手 → 就在那裡，不留空格。一頁 3×3，超過九張框下面有頁點、不抖時左右撥換頁；拖到框的左右邊停一下 → 翻頁，那張還在資料夾裡
- [ ] 28. ★ 從資料夾拖一張到框外（上面或下面）停一下 → 資料夾收起、紙還在手上，可以放到目錄任一格、疊到別張變新資料夾、疊進別的資料夾、拖到邊緣翻頁。在框外馬上放手 → 拿出來放進那頁第一個空格。拖回框裡放手 → 滑回去、什麼都沒變。有兩張的資料夾拖一張出去 → 收起時那格變回剩下那張，放到別格 → 沒有資料夾了；改成疊回剩下那張正中間 → 又變回資料夾
- [ ] 29. 抖動中拖一張停在資料夾磚上 → 磚放大；再停一下 → 資料夾自己打開，紙還在手上；移進框裡放手 → 在那個位置。打開後不進框直接放手 → 回原位，什麼都沒變
- [ ] 30. ★ 上面這些排好之後，把茄記從多工畫面滑掉重開 → 磚的位置、空格、頁、資料夾、磚上的字都跟關掉前一樣
- [ ] 31. 目錄右上 ＋ → 目錄收完，一張空的黃色紙、輸入框升起。回目錄看：在第一頁第一個空格，第一頁滿了才找第二頁
- [ ] 32. 搜尋：打字 → 直接列出符合的行，上面一列色點＋清單名，打中的字茄紫粗體。點一行 → 換到那張、捲到那行亮一下（正在看的這張也一樣）；點清單名那列 → 打開那張。打找不到的字 → 跳「找不到含「那個字」的清單或行」
- [ ] 33. ★ 最近刪除：只刪過行、沒刪過整張，目錄最下面也有這一列，數字有算進刪掉的行。點進去：上面寫「放滿 30 天會自動清掉」，下面是刪掉的清單和「刪掉的行」（右邊小字是哪張）。點一行 →「還原到「那張」」→ 回到那張最上面，劃掉的還是劃掉。點一張 → 系統動作表單（還原、紅字永久刪除）；還原 → 那格還空著就回那格，已經放了別張就照原本的位置回來，不會不見。右上 ⋯ →「清空最近刪除（N）」→ 問過才清，清完看到空狀態的字（**會真的刪掉，裡面沒有要留的才按**）

## 六、在 app 外面

- [ ] 34. ★ 控制中心的「記一行」：在別的 app 裡拉控制中心按一下 → 打開茄記、停在上次那張、輸入框和鍵盤升起；鎖著螢幕按 → 解鎖後一樣。放到鎖定畫面下方按一次；到 設定 → 動作按鈕 指定「記一行」按一次 → 都一樣（送審文案有寫，要確認是真的）
- [ ] 35. 小工具（主畫面三種尺寸、鎖定畫面）：顯示上次那張的名字和前幾行，劃掉的有刪除線。改一行、換一張紙再回主畫面 → 跟著更新。點了 → 打開茄記、停在那張
- [ ] 36. ★ iCloud：改一行，等十秒，到「檔案」app › iCloud 雲碟 › 茄記，那張的檔案時間有更新。完全關掉茄記再開 → 紙都在，開 tunnel 的終端機沒有 iCloud 的警告

## 七、外觀與輔助使用

- [ ] 37. 切深色模式走一圈（紙、九色、＋、選單、切換清單、目錄、資料夾、最近刪除）→ 字都看得清楚，＋ 裡的十字是深色的
- [ ] 38. 設定把文字大小調到最大走一圈 → 字跟著變大、不會被切掉，左上膠囊不會把 ⋯ 擠出去
- [ ] 39. 打開「減少動態」：目錄、切換清單、輸入框改成淡入淡出；拖磚、疊資料夾、拖小點點照樣做得到。打開「減少透明度」：資料夾不霧化，選單、提示條、面板一出來就是不透明的，字都看得清楚，不會先閃一下玻璃
- [ ] 40. 開 VoiceOver：左上念「清單名，切換清單」；切換清單第一列念「新的一張，按鈕」；目錄最下面念「最近刪除，N 項」。在一行上用上下滑選「劃掉」「刪除這行」「往上移」「往下移」；在磚上選「往前移」「往後移」（前後是空格就搬進去）；資料夾裡的紙選「移出資料夾」→ 都做得到
