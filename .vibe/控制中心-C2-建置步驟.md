# 控制中心「記一行」C2 建置步驟（2026-11-01）

> 方案在 `待審-控制中心按鈕.md`（多米選甲）。C1（JS，`qieji://new`）重載就能測；C2 要重建、重裝開發版。

## 建置前

1. **Team ID（建議先補）**：apple-targets 在設定時警告 `ios.appleTeamId` 沒填，新的擴充可能簽不了名。
   到 https://developer.apple.com/account › 會員資格詳細資訊（Membership details）抄「團隊 ID」（10 個英數字），貼給 Claude 寫進 `app.json` 的 `ios.appleTeamId`。
   （原本的小工具擴充沒填也建得起來，所以不補也可能過；補了就少一次失敗的建置）
2. **捏捏史萊姆的 Bundle ID**：還借著 `org.domyweb.qieji` 的話，之後從 TestFlight 裝史萊姆會把這個新建置蓋掉。最好先換。
3. 本機是 Windows，產不出 iOS 專案，Xcode 那一層沒有在本機驗過；第一次 EAS 建置就是驗證。

## 建置

在終端機面板跑（要互動，會問 Apple 帳號）：

```
npx eas-cli@latest build --profile development --platform ios
```

- 會問要不要替新的擴充 `org.domyweb.qieji.controls` 建立描述檔（provisioning profile）、要不要登入 Apple 帳號：都選是
- 建好之後用連結裝到 iPhone（蓋掉舊的開發版，資料會留著）

## 失敗時看哪裡

- 簽章錯誤、提到 `QiejiControls` 或 DEVELOPMENT_TEAM → 補 Team ID（上面第 1 步）再建
- Swift 編譯錯誤提到 `NewLine.swift` → 把錯誤訊息貼給 Claude
