## 二、新檔案怎麼分工

- `Paper/LineList.swift` 原生捲動區本體：位置、掛行收行、最前面那塊（封面頭、空白說明）
- `Paper/LineList+Update.swift` 資料變了怎麼動；`+Edit` 打字與鍵盤；`+Touch` 點、按住、左右滑；`+Drag` 排順序
- `Paper/LineRow.swift` 一行、把手點、LinePitch（行高釘死）、LineTextView；`Paper/LineMeasure.swift` 量高與 LineLook
- `Paper/PaperList.swift` 只剩 SwiftUI 包裝；`ListRemote` 是紙跟清單講話的把手（`remote.list?.refresh()`、`.flash`、`.glider`…）
- `Paper/Composer.swift` 輸入框（UIKit，keyboardLayoutGuide）
- `Design/SoftBlur.swift` 輕霧
- 刪掉：`Paper/ListTouch.swift`、`Paper/LineText.swift`
- 改資料後清單要馬上照新的排：呼叫 `list.refresh(animated:stay:)`，不等 SwiftUI

暫存區（同一個工作階段都讀得到）：`C:\Users\fcharlie\AppData\Local\Temp\claude\c1c8ffcdfe061009\18c11b65-60f2-4ec9-bd02-29a3e277803f\scratchpad`
- `. <暫存區>/env.sh` 之後有：`build`（編 Release 並裝進模擬器，**要看到 `Installed to simulator` 才算裝上**）、`launch`（QIEJI_DEMO=1 假資料）、`shot 名字`、`step N 動作…`（做完截圖 s_N.png）、`mont m 1 2 3`（拼圖 m.png）、`rec`／`stop 名字`、`sheet 名字 起 迄 張數 x0:y0:x1:y1 寬`（逐格拼圖 名字_s.png）、`g 動作…`
- 動作：`tap,x,y`、`hold,x,y,ms`、`drag,x0,y0,x1,y1,步數,每步ms[,按住ms[,放手前停ms]]`、`wait,ms`。座標 402×874
- 打字：`lim ios perform --id $S --action type=pressKey,key=a …`
- 沙盒閒置會被回收：`build` 帶 `--no-create`，回 not found 就重開一台接到同一個模擬器：
  `lim xcode create --attach --simulator-id $S --inactivity-timeout 60m --hard-timeout 240m --label project=qieji --xcode-version 26 --json`，把新 id 寫回 env.sh 的 X。模擬器沒了就 `--ios` 重開一組，S、X 都要換
- 指令前要 `export LIM_DAEMON=false`（env.sh 有）。改檔腳本用 Write 寫成檔再跑，不要用 heredoc 餵含反斜線的內容；長的 heredoc 會被 bash 解壞
- `chg 名字 門檻`：列出哪幾秒畫面有變、變多少（先找時間點再 sheet）。`launch-app` 一定要帶 `-d`，不帶會一直等

- 單元測試：`cd ios-native && lim xcode test . --id $X --scheme Qieji`（84 個，2 個購買的預設跳過）
- 排版與規矩：`lim xcode run . --id $X -- sh tools-check.sh`，再 `lim xcode pull-file formatted.tgz <本機>`，`cp` 進 `ios-native/` 後 `tar xzf` 蓋回來、刪暫存檔。檔案上限 500 行、型別 400 行、不准 `!`、不准寫死色字距秒數（用 Tokens）
- **用完關機**：`lim xcode delete $X`、`lim ios delete $S`，`lim ios list`／`lim xcode list` 確認空的（別的 session 的不要動）
