# 黃金行為（每次改動後都要重玩一遍）

> 2026-11-04：組塊 B、C、D 有幾條寫的是舊畫面（標題區手勢、底部把手、「放進資料夾」選項）。防回歸先回放 `.vibe/送審前總驗.md` 標 ★ 的 15 條，這份等總驗過了再重寫。

## 組塊 A：紙感配色
1. 我在常用的紙上連續編輯十分鐘（記、改字、劃掉、拖順序）→ 看著舒服、眼睛不累，按 ＋ 的輸入框跟紙接得起來
2. 我從 ⋯ 換顏色把九色輪一遍 → 每一色都是淡的紙色、九色分得出來，標題、行、「＋ 新增一行」都看得清楚
3. 我切到深色模式再輪一遍九色 → 深底淺字、不刺眼、九色分得出來
4. 我打開目錄 → 每塊磚跟點進去的紙同色；色點還是原本飽和的那組

## 組塊 B：用標題區換紙、開目錄
1. 我已釘兩張，再釘第三張 → 一步跳出「已釘滿兩張／要換掉哪一張？」；點一張就換掉並出現「復原」，點取消什麼都不變
2. 我點標題 → 什麼都不變（多米 2026-11-02 改：要改名從 ⋯ 按「改名字」）；我點標題下的分段把手 → 打開目錄；點第一行 → 改那一行，不會開目錄
3. 我釘選／取消釘選 → 把手段數馬上跟著變，亮的那段是現在這張
4. 我在標題區往下拉 → 目錄跟著手指從上面垂下來，拉一段放手就打開；從第一行往下拉不會拉出目錄
5. 目錄開著 → 點下面露出的紙、或把底部把手往上推，目錄收回；點磚換紙、點新的一張輸入框馬上升起
6. 我釘了兩張，在標題區左右滑 → 標題跟著手指走，放手換到另一張、把手亮段跟著換；只滑一點點會彈回；到頭被拉住彈回；從第一行左右滑照舊劃掉／刪除那一行

## 組塊 C：目錄照我手排的位置放
1. 我改了一張排在後面的紙，再打開目錄 → 它留在原位，不跳到最前面；關掉 app 再開順序不變
2. 我開新的一張寫一行 → 目錄裡它在最後一格；沒寫就換走 → 不留空格
3. 目錄沒有「已釘選／其他」兩段；釘選的磚有圖釘，釘選或取消時磚不移動
4. 我的紙多到一頁放不下 → 目錄下面有圓點，左右滑整頁翻過去、圓點跟著亮；搜尋會找所有頁的紙
5. 我長按一塊磚 → 跳選單（顏色、改名字、刪除、編輯目錄）；長按後直接拖 → 進抖動、磚跟手，拖到別的位置放下，其他磚讓位，關掉再開順序是我排的
6. 抖動時往上推底部把手、點磚都不會收目錄或換紙；點完成或露出的紙才停
7. 抖動中拖著一塊磚到右邊緣停一下 → 翻到下一頁、磚還在手上，放到那頁某格 → 關掉再開它在那裡
8. （C2）我打開茄記等幾秒 → 「檔案 › iCloud 雲碟 › 茄記」裡有 `layout.json`；刪 app 重裝、紙回來後 → 目錄順序跟刪之前我排的一樣
9. （C2）我只改字、記一行、不拖 → 目錄順序不變

## 組塊 D：資料夾
1. 我長按一塊紙磚選「放進資料夾…」→ 第一次會變成一個打開的「新資料夾」、名字可以直接改；之後會問放進哪一個 → 紙進去了，目錄上是資料夾磚（名字＋裡面紙的小色塊）
2. 我點資料夾磚 → 打開看得到裡面的紙，點一張就換到那張；點外面收起
3. 打開資料夾，按住一張拖到框外放手 → 回到目錄、排在資料夾後面；最後一張拖出去資料夾就不見（2026-11-02 晚起沒有「移出資料夾」文字選項）
4. 關掉 app 再開、刪 app 重裝 → 資料夾和裡面的紙都在，順序不變
5. （iOS 對照）按住目錄格子的空白處 → 進抖動；抖動中點空白處 → 停；抖動中點資料夾 → 打開，裡面的紙跟著抖、手指一動就拿起來
