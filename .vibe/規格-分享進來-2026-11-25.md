## 使用者看到的

- 在別的 app 分享文字或網址 → 選「茄記」→ 原畫面變暗、底部升起奶油白小卡（長得跟 app 裡的輸入框同一個樣子），**鍵盤不升**
- 卡上：要記的字（可以點了改，點了才升鍵盤、卡跟著鍵盤上去；長了在卡裡捲）；下面一排：✕、小方磚＋「放進 今天想到的」（不能點）、✓
- ✓：先寫進收件匣（按下就寫），卡沉下去、暗幕淡掉，回到原本的 app
- ✕、點卡外面：取消，什麼都不留。**字改過時點外面只收鍵盤、不取消**（改的字會丟）
- 字有好幾行：卡左上方冒茄紫膠囊「拆成 N 行」（跟 app 的 2A 同一個樣子）；按了＝拆成 N 行記下並收起。超過 1000 行不給
- 分享網頁（4A）：一則，標題一行、網址一行。沒標題就只有網址；標題或文字裡已經有那個網址就不重複；文字＋網址＝文字一行、網址一行
- 只收文字和 http/https 網址；圖片、檔案不收。拿不到可用的字：卡上寫一句、只留 ✕
- 下次打開茄記（或回到前景）：字進那張紙最上面、亮一下
- 沒有可顯示的紙名時寫「放進茄記」
- 寫收件匣失敗（App Group 拿不到、空間滿）：卡留著、字留著，寫一句「沒記成，字還在這裡，可以先複製」，不准默默關掉

## 資料

- `Shared/ShareInbox.swift`（app 與擴充都編）：App Group `group.org.domyweb.qieji`
  - 名字：`ShareTarget { id, title, glyph, color }`，放 App Group 的 UserDefaults（鍵 `shareTarget.v1`），nil＝拿掉
  - 收件匣：App Group 容器裡的資料夾 `Inbox/`，一次分享一個檔 `<第一行 id>.json`：`{ v:1, note: 紙id?, at: 毫秒, lines:[{id,t}] }`。原子寫入＋`completeUntilFirstUserAuthentication`
  - 行的 id 在分享當下用 `Ident.make` 定好
  - 上限：一則字最多 20,000 字（超過截斷，卡上講一聲）；讀檔時檔案超過 512KB、格式不對、v 不是 1、行數 0 或超過 1000、id 不是 9–13 個 `[0-9a-z]`、字是空的 → 跳過不刪、不當掉、不影響其他檔，log 只寫數量不寫字
  - 資料夾路徑要能從外面傳（測試用暫存資料夾）
- `Ident`、`Clock` 從 `Core/Model.swift` 搬到 `Shared/Ident.swift`（內容不改）；`Lines.splitPasted` 的本體搬到 `Shared/LineSplit.swift`，`Lines.splitPasted` 改成呼叫它（行為不變）。組字（標題＋網址那些規則）寫成純函式 `Shared/ShareText.swift`，要有單元測試

## app 這邊（`Core/StoreInbox.swift`）

- **放哪張**：能記的＝沒刪、不是記事本（isText）、沒上鎖、`Lines.room > 0`（拆行時要 ≥ 行數）。順序：檔裡寫的那張 → 現在這張 → `disk.recent` 依序 → 其他紙照 updated 新到舊。都沒有：開一張新的空白紙（進目錄第一個空位，不換過去）
- **推名字**：挑出來的那張的 `Labels.label`、`Labels.glyph`、color。跟 `pushWidget` 同樣時機（存檔成功、換紙後延遲那次），不看買了沒（放在 `fullKnown` 的 guard 前面）；內容一樣不寫。**上鎖那一刻馬上推**（`PaperView` 上鎖成功那裡），不等存檔。`disk == nil`（假資料、測試）不推
- **併進紙**：boot 之後、`scenePhase == .active` 各做一次。讀檔在背景佇列，沒東西就什麼都不做；有才回主執行緒併
  - `loaded`、沒 `frozen`、`disk != nil` 才併
  - 已經在任何一張紙（行或最近刪除）的 id 不再加
  - 檔案照 at 舊到新，每則插到最上面（新的在最上）；拆的行保持原順序；算改過（updated）
  - 一次改完 `edit` 一次，存檔用 `saveSoon` 加一個完成回呼；**存成功才刪那幾個檔**。全部都是已知 id 也照樣存一次再刪
  - 存失敗：檔留著，下次再來（不會記兩次）
  - 放進現在這張：用 `store.seek`／`seekAsk` 那條讓它亮一下（先看 `PaperList.swift:72`，正在打字、拖曳、輸入框開著時不准捲走或搶焦點；不合適就只讓它淡入）。放進別張：提示條「已放進「X」」，多張時「已放進 N 張」
- **清除所有資料**：`Store.wipe` 一起清收件匣與共用區的名字；清不掉就回 false
- 上 iCloud 就是平常存檔後那條 `pushSoon`，不另外寫
