## 必查清單

### 本機資料儲存（MASVS-STORAGE）
- [ ] 不存帳號、密碼、token（茄記現在沒有，加了就要放 Keychain，不准放 AsyncStorage）
- [ ] 紙的內容只放在 app 自己的沙盒（AsyncStorage）與使用者自己的 iCloud 雲碟；不寫到其他 app 讀得到的地方
- [ ] 不把紙的內容印到 log（`console.*` 只印錯誤，不印紙或行的字）
- [ ] 不把紙的內容放進網址
- [ ] 小工具與控制中心擴充只拿得到它們要顯示的那一點點（紙名、前幾行）
- [ ] 退到背景時要不要遮內容：記事類一般不遮；鎖定畫面小工具會露出前幾行，是使用者自己加的

### 加密（MASVS-CRYPTO）
- [ ] 不自己做加密；需要時用 iOS 原生
- [ ] `Math.random()` 只能拿來產生不需要保密的 id，不准拿來做任何秘密

### 網路（MASVS-NETWORK）
- [ ] 沒有網路連線；加了就一律 HTTPS、不關 ATS、不忽略憑證錯誤
- [ ] `app.json` 不准加 `NSAllowsArbitraryLoads`

### 登入（MASVS-AUTH）
- [ ] 沒有登入；加了要走 Sign in with Apple 或標準 OAuth，token 進 Keychain

### 平台互動（MASVS-PLATFORM）
- [ ] 任何 app 都能打開 `qieji://` 網址：網址只准「打開畫面、升起輸入框」，不准寫入、刪除、改設定或帶資料進來
- [ ] 不用 WebView；要用時關掉檔案存取、不暴露原生方法

### 分享延伸與收件匣（2026-11-25 定稿；3D＋5B。勾選留到上線前自查再打）
被打中會怎樣：分享進來的字在共用區留著沒清、被別的地方讀到；或同一行記兩次、記不見；或面板露出上鎖那張的名字。
- [ ] 面板只收文字和網址，不收檔案、圖片；太長的截斷並講一聲，不讓延伸把記憶體吃光
- [ ] 面板不連網、不執行網頁裡的程式（標題用系統給的，不用 `NSExtensionJavaScriptPreprocessingFile`；真的要用先回來過這份）
- [ ] 面板不讀紙的內容，只讀 app 放在 App Group 的紙單（多米 11/25 選 5B）：預設那張、釘選、最近開過的，每張只有 id、名字、圖示字、顏色，最多 20 張
- [ ] 上鎖的紙、記事本、已刪除的紙：名字不放進 App Group。上鎖那一刻，共用區裡那張的名字馬上拿掉
- [ ] 紙單存成 App Group 的檔（`ShareTargets.json`），每次開面板從磁碟讀，不放 UserDefaults（跨行程會讀到舊的，模擬器實測過）。寫不進去不准留著舊的
- [ ] 附件：總共等 5 秒；大段文字先截再處理，不在主執行緒做。沒拿到的要講一聲
- [ ] 收件匣放 App Group 自己的資料夾，一次分享一個檔、原子寫入、`completeUntilFirstUserAuthentication`；不放 UserDefaults
- [ ] 開著同步：等 iCloud 這一輪拉完才併（最多約 15 秒），不拿這台的舊字蓋掉別台剛改的
- [ ] 併進紙：先存檔成功，才刪收件匣那個檔。行的 id 在分享當下就定好，已經在紙上（含最近刪除）就不再加，當掉重來不會記兩次
- [ ] 收件匣的檔當外面來的資料：格式不對、太大、id 不像茄記的就跳過，不當掉、不影響其他檔
- [ ] 那張不見、上鎖、滿了：放下一張能記的；一張都沒有就開一張新的。字不能丟
- [ ] 存檔讀不出來（frozen）時不併、不刪收件匣
- [ ] 設定「清除所有資料」要一起清收件匣與共用區的名字
- [ ] 併進紙＝跟平常記一行走同一條路，開著同步就會上 iCloud（多米 2026-11-25 點頭）
- [ ] 字不印到 log、不放進網址；延伸不開 `qieji://`

### 程式碼品質（MASVS-CODE）
- [ ] Expo SDK 跟著最新穩定版
- [ ] 套件從 npm 官方裝、`package-lock.json` 鎖版本；`patches/` 裡的修補每次升版檢查還要不要
- [ ] 正式版用 `production` 建置設定，不帶開發選單

### 授權：誰算「買了」（MASVS-AUTH，1.1 起）
被打中會怎樣：付了錢卻沒解鎖（退款、一星評論）；沒付錢卻解鎖（少賺、審查退件）；或解鎖狀態一亂，iCloud 同步被關掉，兩台手機的紙對不上。
- [ ] 「買了沒」只從 StoreKit 拿，只信 Apple 簽章驗過的交易（StoreKit 2 的已驗證交易）；驗證失敗一律當沒買
- [ ] 本機的「已解鎖」記號只是快取：每次打開 app、回到前景時以 StoreKit 重算；快取跟 StoreKit 對不上，以 StoreKit 為準
- [ ] 讀不到 StoreKit（沒網路、App Store 掛了）時，沿用上次確認過的結果，不要突然把買過的人鎖住；從來沒確認過就當沒買
- [ ] 退款後 Apple 會撤銷那筆交易（有撤銷日期），下次重算要重新鎖上
- [ ] 家人共享來的交易也算買了
- [ ] 小工具、控制中心擴充只**讀**解鎖記號，不能自己改；`qieji://` 網址不能解鎖任何東西
- [ ] 不寫死價格：畫面上的價格用 StoreKit 回傳的在地價格
- [ ] **鎖住只能停功能，不准刪任何資料**：iCloud 同步鎖住時，手機上的紙與 iCloud 雲碟裡的檔都不動

### 個別上鎖（1.1 追加，2026-11-14）
被打中會怎樣：以為鎖住了，內容卻從別的地方露出來（iCloud 雲碟的檔、小工具、搜尋）；或鎖被別台的同步解開；或鎖到自己打不開。
- [ ] 上鎖是「在 app 裡擋著」，不是加密：對外文字（付費頁、支援頁、隱私權政策）不准寫成加密、保險箱
- [ ] 上鎖的紙不上傳 iCloud；上鎖那一刻拿掉 iCloud 上那張的檔（不立墓碑）。拿不掉要跟使用者講
- [ ] 上鎖的紙：沒驗過不畫內容；小工具、搜尋、分享、複製都拿不到內容
- [ ] 鎖只算這支手機的事：iCloud 來的檔不能把這台的紙鎖上，也不能把這台鎖著的紙解開
- [ ] 驗證只用系統的（Face ID／手機密碼），茄記不存任何密碼、不碰臉部資料
- [ ] 開鎖、解除上鎖不看買了沒；手機沒有任何鎖的時候放行，不把人關在外面
- [ ] 封面圖的檔名代號只准小寫英數（外面進來的檔不能指到別的路徑）；從 iCloud 抓下來的圖先驗格式與大小

### 抗逆向（MASVS-RESILIENCE）
標準寫「處理金錢必做」，這裡照茄記的規模定範圍（多米 2026-11-11 待確認，不回照這樣）：
- [ ] 反竄改：只信 Apple 簽章過的交易（上一段第一條），自己不另外存「已購買」憑證
- N/A 越獄偵測、程式碼混淆、偵測除錯器：一次 NT$150 的解鎖，被破解只影響那台破解的手機，不影響別人的資料與錢；做了反而可能誤擋正常使用者

### 隱私（MASVS-PRIVACY）
- [ ] 不要任何權限（目前一個都沒要）
- [ ] App Store 隱私標籤照實填（目前：不蒐集任何資料）。1.1 只用 Apple 自己的內購、不接 RevenueCat 這類第三方購買服務；送審前查證「購買記錄」那格要不要勾
- [ ] Privacy Manifest（`PrivacyInfo.xcprivacy`）有宣告用到的「需要理由的 API」
- [ ] 使用者刪得掉自己的資料（永久刪除、刪 app、iCloud 雲碟裡刪檔案）
