## ✅ 必須做到（可操作測試句）
- [ ] 我釘了兩張、停在第一張，手指放在標題區（清單名或時間那行）往左滑，標題應該跟著手指往左移；放手就換到第二張，新的標題從右邊滑進來，把手亮的那段跳到第二段
- [ ] 我在第二張往右滑，應該回到第一張，標題從左邊滑進來
- [ ] 我只滑一小段（不到兩公分）慢慢放手，標題應該彈回原位，不換張
- [ ] 我滑的距離短但甩得快，也應該換張
- [ ] 我停在一張沒釘的紙（把手三段、亮最左），往左滑應該換到第一張釘選的；換過去之後把手變成兩段，再往右滑到頭只會彈回，那張沒釘的要從目錄點才回得來
- [ ] 我已經在最左邊還往右滑（或最右邊往左滑），標題應該只跟一點點、像被拉住，放手彈回，不換張，也不跳任何提示（多米 2026-11-02 定甲：只拉住彈回，不照原型跳「已經是第一張」）
- [ ] 我一張都沒釘（把手只有一段），往左、往右滑都應該只有被拉住的感覺、彈回，不換張
- [ ] 我在標題區斜斜地拉：先往下動就是目錄垂下來、先往左右動就是換張，一次只會發生一種，不會一邊換張一邊拉出目錄
- [ ] 我從第一行開始往左或往右滑，應該照舊是刪除或劃掉那一行，不會換張
- [ ] 我點標題正在改名時，在名字上左右拖，應該是在移游標或選字，不會換張
- [ ] 我按 ＋ 打字打到一半，直接在標題區左右滑換張，打的那句應該留在原本那張的最上面，不會丟
- [ ] 我開了一張新的、什麼都沒寫就左右滑換走，那張空白的應該不會留在目錄裡（跟從目錄換紙一樣）
- [ ] 我換過去再換回來，時間那行的「多久前改的」不會變成「剛剛」（換張不算修改）
- [ ] 換張之後，點標題照舊是改名、點把手照舊開目錄、往下拉照舊開目錄
- [ ] 我打開系統「減少動態」，換張應該直接淡入淡出，標題不左右滑來滑去
- [ ] 我開 VoiceOver，點兩下把手打開目錄、點一塊磚，照樣能換紙（左右滑是給手指的捷徑，VoiceOver 走目錄）

## ⛔ 絕對不准做
- 不准動到：行的點、左右滑、按住、拖把手；＋ 輸入框；⋯ 選單；B1 釘選上限與換一張的選單；B2 把手的樣子、點標題改名、點把手開目錄；B3 往下拉開目錄的手感與面板
- 不准讓左右滑的範圍超過分隔線（第一行以下一點都不能吃到）
- 不准改 `swipeSet` 的排法（釘選照建立先後、沒釘的排最左、最多三段）；換張不准動到紙的修改時間，不准改目錄裡的順序
- 不准擅自加：滑到頭跳「已經是第一張／最後一張」提示、滑到頭跳到目錄的下一張、最右邊再滑繞回最左邊、觸覺震動、捏合、第一次的教學提示、VoiceOver 自訂動作
- 目錄開著的時候不准能左右滑換張（面板蓋著，手勢不准穿過去）

## 🎯 每條的意圖
- 「標題跟著手指走」是為了手一動就知道會換張，滑一半反悔還收得回來（2-4 連續回饋）
- 「新的從另一邊滑進來、把手亮段跟著跳」是為了換完知道自己換到哪、在第幾張（2-5，跟照片左右翻同一套）
- 「滑一小段彈回、甩一下就換」是為了不小心碰到不會換走，想換的時候又不用滑很遠
- 「只在釘選的之間、沒釘的換走就不回來」是定案 A：左右滑到的永遠是常用的那兩張，張數少記得住；其他的紙走目錄
- 「到頭被拉住」是為了告訴你這邊沒有了，又不會什麼反應都沒有讓你以為手勢壞了
- 「先動哪個方向就是哪個」是因為同一塊標題區已經有往下拉開目錄（B3），兩個一起動會亂（lessons：同一塊畫面已有的手勢先列）
- 「第一行以下不換張」是因為行上已經有左右滑劃掉／刪除，範圍停在分隔線才分得開
- 「改名時不換張」是因為改名時手指在字上拖是要移游標
- 「打到一半的字不丟、空白紙不留、時間不變」是因為換張的方法變了，換紙的收尾規矩不准跟著變
- 「減少動態、VoiceOver」是因為自己做的手勢系統不會幫忙，要自己補（2-11）
