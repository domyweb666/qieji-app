## ✅ 必須做到（可操作測試句）
- [ ] 我長按目錄裡一塊紙磚 → 選單多一項「放進資料夾…」
- [ ] 還沒有任何資料夾時點「放進資料夾…」→ 那張紙的位置變成一個資料夾磚，資料夾自動打開，上面的名字「新資料夾」可以直接打字改名
- [ ] 已經有資料夾時點「放進資料夾…」→ 跳出清單：每個資料夾的名字＋「新資料夾」＋取消；點一個資料夾 → 紙從目錄消失、進到那個資料夾的最後面
- [ ] 資料夾磚跟紙磚一樣大：上面是資料夾名，下面一排小方塊，顏色是裡面紙的顏色（最多四個，更多的寫 +N）
- [ ] 點資料夾磚 → 資料夾在目錄上面打開，看得到名字和裡面的紙；點裡面一張 → 換到那張紙、目錄收起；點資料夾外面 → 資料夾收起
- [ ] 打開的資料夾點名字 → 可以改名；打完收鍵盤或點外面就存；名字清空就維持原來的名字
- [ ] 資料夾磚長按 → 選單「改名字」「編輯目錄」；資料夾磚也能跟紙磚一樣拖換位置、拖到邊緣翻頁
- [ ] 資料夾裡的紙長按 → 選單有顏色、改名字、刪除、「移出資料夾」；移出 → 紙回到目錄、排在資料夾後面一格
- [ ] 資料夾只剩一張時移出去 → 資料夾不見，那張紙站在資料夾原本的位置
- [ ] 資料夾裡的紙刪掉 → 進最近刪除；從最近刪除還原 → 回到資料夾裡
- [ ] 資料夾裡全部的紙都在最近刪除 → 目錄看不到這個資料夾；還原一張就回來
- [ ] 搜尋時會找到資料夾裡的紙（直接列出那張紙，不顯示資料夾）
- [ ] 正在看的紙在資料夾裡 → 資料夾磚有框（跟正在看的紙磚一樣）
- [ ] 新的一張照舊排在目錄最後面，不會跑進資料夾
- [ ] 關掉 app 再開、刪 app 重裝等 iCloud 拉回來 → 資料夾、名字、裡面有哪幾張、順序都在
- [ ] VoiceOver：資料夾磚念「資料夾，名字，幾張」，動作有改名字、往前移、往後移；資料夾裡的紙動作有移出資料夾

## 🎯 每條的意圖
- 「放進資料夾…」在選單裡，是因為疊的動作是隱藏手勢、又容易疊錯，要先有看得見的入口（2-7），VoiceOver 也做得到
- 「新資料夾自動打開、名字可以打」跟 iOS 疊出資料夾後的樣子一樣，取名就在當下
- 「小色塊」是因為九色裡很多張同色，看得到裡面是哪幾張顏色的紙比較好認（多米選）
- 「最後一張移出就消失」跟 iOS 一樣，不留空殼要自己清（多米選）
- 「刪掉還原回資料夾」「全部在最近刪除就看不到資料夾」延續 C1 的座位規則：刪除不弄丟位置
- 「重裝回來」是 C2 的理由延伸：手排的資料夾跟手排的位置一樣不能白排
