# 標準清單（本次：片 A1 紙感配色｜組塊 A）

> 設計定案：`.uiux/審查紀錄.md`「紙的配色＋目錄改成主畫面」✅ 那段（乙 紙感九色淺色值）
> 範圍：只換九種紙的底色與格線色（淺色、深色、增加對比三組）。色點、介面色、字色都不動

## ✅ 必須做到（可操作測試句）
> 走查（多米 2026-11-01 晚，原話）：「主要重視的還是編輯體驗，質感是方便長久看是順眼的。」→ 第一條改成編輯十分鐘，九色輪一遍降成第二順位
- [ ] 我在常用的那張紙上連續編輯十分鐘（按 ＋ 記幾行、點一行改字、劃掉、拖順序），應該看著舒服、眼睛不累，底不刺眼、字也不會淡到要瞇眼
- [ ] 我按 ＋ 跳出輸入框時，輸入框跟後面那張紙的顏色應該接得起來，不會像突然貼上一塊不相干的白
- [ ] 我打開一張紙，從 ⋯ 換顏色把九色輪一遍，應該看到每一色的底都比改版前淡、像紙，九色彼此還分得出來
- [ ] 我打開目錄，應該看到每塊磚的顏色跟點進去那張紙的底色一樣
- [ ] 我在任何一色的紙上看標題、行的字、「＋ 新增一行」、標題的提示字、劃掉的行，應該都看得清楚，沒有哪一色特別吃力
- [ ] 我看行跟行之間的格線，應該比以前淡，但還看得出一行一行
- [ ] 我把手機切到深色模式，再把九色輪一遍，應該看到深底淺字、不刺眼、九色還分得出來，不是九張都一樣灰
- [ ] 我看顏色面板、目錄磚上的色條、最近刪除的色點，應該跟以前一樣是比較飽和的那組點點，沒變淡
- [ ] 我回到主畫面看桌面小工具，等它更新之後，底色應該也換成新的那色
- [ ] 我打開改版前就有的紙，應該顏色自動換成新的對應色，紙的內容、順序、選的哪一色都沒變

## ⛔ 絕對不准做
- 不准動到：紙上的手勢（點、左右滑、按住、拖把手）、輸入框、目錄的排列與選單、最近刪除、iCloud 同步、控制中心按鈕
- 不准改：九色的名字與存檔用的代號（改了舊紙會認不得顏色）；介面色（首頁底、卡片、紫色強調、危險紅）；字色；色點色
- 不准擅自加：新的顏色、漸層、紙紋材質、換色動畫
- 不准拿淺色值直接降亮度當深色（審查紀錄定案）
- 對比檢查表不准用目測，要用 `gen_pairs.py`＋`contrast.py` 算，四種模式全部重算

## 🎯 每條的意圖
- 「編輯十分鐘看著舒服」是這片的主目的：茄記最常做的事是在紙上記和改，顏色是為了長時間看著順眼，不是為了好看一眼
- 「輸入框跟紙接得起來」是為了編輯時不被一塊突兀的色塊打斷（輸入框用的是介面的卡片色，這片不改它；接不起來就記下來，另開一片處理）
- 「換九色每一色都比較淡」是為了讓 app 打開就像一張紙，不是一塊色板（多米選乙的理由）
- 「磚跟紙同色」是為了在目錄裡一眼認出要找的那張
- 「每一色的字都看得清楚」是為了不讓哪個顏色變成不能用的顏色（2-6：深字淺底、4.5:1）
- 「格線變淡但看得到」是為了紙感：線不搶字，但手指還知道一行到哪裡
- 「深色模式另調」是為了晚上用不刺眼，而且九色在暗處也分得出來（3-5：降飽和，不是反轉）
- 「色點不變」是為了紙底變淡之後，選顏色時靠色點還分得出九色
- 「小工具跟著換」是為了桌面上看到的跟打開 app 看到的是同一張紙
- 「舊紙自動換」是為了不用一張一張重選顏色
