## 1. 面板開著時切去茄記上鎖、刪紙、改名，切回來還是舊名單 → 修好

**原因**：面板只在打開那一下讀一次紙單，之後 app 怎麼改它都不知道。app 那邊本來就寫得很快（上鎖馬上寫、改名刪紙存檔就寫、切走時也會存），是面板沒有再讀。

**怎麼修**
- app 寫完紙單（內容真的變了才算，拿掉整份也算），用系統的跨程式通知喊一聲「紙單換了」，只有這句、不帶任何名字（`Shared/ShareInbox.swift` 的 `announce`、`ping`）
- 面板開著時聽三件事，任何一件就重讀紙單（`QiejiShare/ShareController.swift` 的 `watchTargets`）：
  - app 喊的那一聲（茄記和 Safari 並排、或切回來時 app 還沒寫完，都靠這個）
  - 原本的 app（Safari 等）回到前景
  - 原本的 app 重新變成作用中
- 重讀後：
  - 自己從選單挑過的那張還在 → 繼續選它（名字改了也跟著改）
  - 挑的那張不在了（上鎖、刪掉、滿了）→ 回到第一張（預設那張）
  - 沒挑過 → 一律顯示第一張（跟新開面板一樣）
- 就算按 ✓ 的那一瞬間名單還沒換過來，記的那張已經上鎖：app 併進紙時本來就會擋，放到下一張能記的（原本的規則，沒動），不會寫進上鎖的紙

**模擬器走過**（limrun iOS 26.4，真機沒驗）
- 改前重現：Safari 分享 → 面板 → 切去茄記把一張「未命名」改名成 Shop → 切回去，面板還寫「放進 未命名・11/26 02:59」
- 改後：在選單挑第二張 → 切去茄記把預設那張改名 Milk → 切回去，選單第一張變 Milk、挑的那張還勾著
- 改後：切去茄記把挑的那張刪掉 → 切回去，面板換成「放進 Milk」，選單裡那張不見了；按 ✓，字進了 Milk
- 上鎖在模擬器做不到（要買完整版、要臉），靠單元測試：上鎖那一刻紙單換掉而且有喊

## 2. 同名、同一分鐘開的兩張分不出來，選單裡還折兩行 → 修好

**原因**：同名的紙只會加「日期」或「日期＋幾點幾分」，同一分鐘開的就一模一樣；「未命名・11/25 10:16」在選單裡放不下一行。

**怎麼修**（`Qieji/Core/StoreInbox.swift` 的 `InboxMerge.names`）
- 只有撞名的才加後面那段，從短的試起，挑第一個在同名的裡面只有它自己的：
  日期（11/25）→ 幾點幾分（10:16）→ 日期＋時分 → 時分秒（10:16:05）→ 日期＋時分秒
- 同一秒開的（幾乎不會有）：後面的加（2）（3）
- 底下那排「放進 X」放不下時改成從中間省略，後面分得出來的那段看得到（`QiejiShare/ShareParts.swift`）

**模擬器看過**：五張沒取名的，選單是「未命名・03:09:41」「未命名・03:09:36」「未命名・03:08:50」「未命名・03:08:16」「未命名・03:07」，每行都一行放得下。改前同樣情形是三行「未命名・11/26 02:59」這種、每行折兩行。

## 代決（多米可推翻）

1. 同名、同一天、不同時間的：只寫時間「未命名・10:16」，不再寫「未命名・11/25 10:16」。日期一樣，加了也分不出來，還會擠成兩行
2. 分不出來時加「時間到秒」，不加第一行字或行數：安全標準說紙的內容不准放進共用區，行數也算從內容來的。秒數不好記，但一定分得出來，平常很少用到（要兩張同名、同一分鐘開）
3. 挑過的那張還在就跟著它；沒挑過的照最新的預設那張（等於重新打開面板會看到的）。挑的那張不見了就默默回到預設，不跳提示（「放進 X」那排會換名字）
4. 「放進 X」放不下時從中間省略（以前是從尾巴省略），名字很長、沒撞名的也一樣
5. 茄記自己的切換清單（點左上名字那張）同名的還是好幾個「未命名」，沒動：這次只修面板，那邊每張都有自己的位置可以點

## 要多米真機看的

- H1 Safari 分享 → 茄記面板開著 → 切到茄記，把面板上看得到的一張上鎖 → 切回 Safari：選單裡沒有那張、底下那排也不是它的名字
- H2 同上，改名一張 → 切回去：選單上是新名字；刪一張 → 切回去：不見了
- H3 在選單挑一張別的 → 切去茄記把那張上鎖 → 切回去：底下換回預設那張；按 ✓，字不在上鎖那張（打開它看）
- H4 開兩張沒取名的紙、同一分鐘內各記一行 → 分享進來看選單：兩行不一樣、每行一行放得下（最大字級可以折）
- H5 iPad 或並排（如果有）：面板和茄記同時開著，在茄記上鎖，面板不用切換就換掉
